% This file defines the custom front-matter pages for Volume I:
%
%   - half-title page        (\halftitle)
%   - title page             (\mlsysTitleBlock)
%   - copyright page         (\copyrightpage)
%   - dedication page        (\dedicationpage)
%
% These commands are used by the Quarto titlepage extension and by the custom
% before-body template:
%
%   _extensions/mlsysbook-ext/titlepage/before-body.tex
%
% The intended academic book front-matter sequence is:
%
%   cover art       (rendered by the Quarto coverpage mechanism)
%   half-title      (rendered by \halftitle)
%   blank verso
%   title page      (rendered through the titlepage extension using
%                    \mlsysTitleBlock from the YAML titlepage-theme elements)
%   copyright page  (rendered by \copyrightpage)
%   dedication page (rendered by \dedicationpage)
%
% The half-title shows only the book title -- no author, publisher, or date.
% The title page defines the main title, author block, affiliation, and publisher
% block through separate content/style/layout commands. This keeps the visual
% design easy to adjust without changing the titlepage extension itself.
%
% Color note:
% \color{crimson} resolves through the alias chain in header-includes.tex
% (\colorlet{crimson}{accentcolor}). For Volume I production, accentcolor is
% Harvard crimson; for copyedit/proof PDFs, the corresponding theme-colors file
% may set accentcolor to black, which cascades here automatically.
%
% IMPORTANT:
% This file must be loaded via include-in-header, not include-before-body.
% The commands need to be available before \begin{document}, because the Quarto
% titlepage extension expands the titlepage elements during document generation.
%
% YAML connection:
% The PDF YAML should include this file, for example:
%
%   include-in-header:
%     - file: "tex/frontmatter-vol1.tex"
%
% and the titlepage theme should call the custom title block:
%
%   titlepage-theme:
%     elements: [ "\\mlsysTitleBlock" ]
%
% =============================================================================
