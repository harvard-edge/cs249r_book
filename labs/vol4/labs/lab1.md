## 1. Learning Objectives

By the end of this lab, you will be able to:

- Derive the forward kinematic model of an N-DOF serial manipulator using Homogeneous Transformations.
- Formulate the coordinate transform matrices directly from a Unified Robot Description Format (URDF) file.
- Implement forward kinematics algorithms on an MCU to track real-time end-effector pose during physical robot actuation.
