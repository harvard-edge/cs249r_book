    engine.solvers.plant

    engine.solvers.plant

    Physical-plant solvers: the stopping, actuation, heat, and power budgets of an embodied machine (added 2026-10-20).

    Domain implementations behind mlsysim.solvers (the public import path, derived from engine.solvers.__init__). Each model takes stated inputs and returns every intermediate a budget quotes, so a chapter, a slide deck, and a lab read the same arithmetic. The equations themselves live in physics/ (robotics/stopping.py, drivetrain.py, motors.py); these models only compose them into the budgets of one machine.

    Composes calc_braking_limits for a wheeled base driven by direct-drive hub motors at a configured current limit, adds the rated-current torque ceiling and the inspected-floor traction ceiling (all weight on the driven wheels), and checks the terminal voltage braking and driving need at speed.

    ContinuousDeratingModel

    engine.solvers.plant.ContinuousDeratingModel()

    Installed continuous torque relative to the catalog rating.

    Continuous torque scales as sqrt((T_max - T_amb) / theta): a hotter ambient and a larger installed thermal resistance each cut it.

    Parameters
    Name Type Description Default

    Name Type Description
    ContinuousDeratingResult Dimensionless installed/catalog torque shares for ambient alone and combined thermal effects.

    DiagnosticCoverageModel

    engine.solvers.plant.DiagnosticCoverageModel()

    Diagnostic coverage that leaves at most target of a raw fault rate unmitigated, and the zero-miss injection campaign that demonstrates it (added 2026-10-20).

    Rates are in FIT (faults per 10^9 hours). The raw rate is the sum of the strata; coverage C_diag = 1 - target / raw. Each injection misses with probability 1 - C_diag, so n zero-miss injections bound it at confidence C when n >= ln(1 - C) / ln(C_diag); the rule of three approximates n by 3 / (1 - C_diag). Drawn in proportion to the rates, each stratum receives its share of the n injections.

    Methods

    Name Description
    solve Diagnostic coverage that leaves at most target of a raw fault rate unmitigated, and the zero-miss injection campaign that demonstrates it (added 2026-10-20).
    solve
    engine.solvers.plant.DiagnosticCoverageModel.solve(strata, target, confidence)

    Diagnostic coverage that leaves at most target of a raw fault rate unmitigated, and the zero-miss injection campaign that demonstrates it (added 2026-10-20).

    Parameters
    Name Type Description Default
    strata Dict[str, float] Mapping from stratum names to nonnegative fault rates (FIT), positive total. required
    target float Positive residual rate below the total, in FIT. required
    confidence float One-sided confidence level in (0, 1). required
    Returns
    Name Type Description
    DiagnosticCoverageResult Fault-rate total in FIT, dimensionless coverage and shares, and injection counts.
    Notes

    Equation: Raw rate is sum(strata.values()); required coverage = 1-target/raw_rate. The exact real-valued trial threshold is ln(1-confidence)/ln(coverage), rounded upward for injections. Stratum share = stratum_rate/raw_rate; allocation = injections*share.

    Assumptions: Independent representative injection trials and proportional stratum allocation.

    Excludes: Unequal detection probability by stratum, common-cause dependencies, and certification.

    References

    Derivation: Residual faults are the raw rate times the missed fraction. For independent representative injections, observing no misses has probability coverage^n. Inverting that probability gives the trial threshold. Proportional allocations are expected counts, not a rounded stratified test design.

    Examples
    >>> from mlsysim.core.units import Q_ as Q
>>> DiagnosticCoverageModel().solve({"sensor": 100.0}, 1.0, 0.95).injections > 0
True

    DriveBusModel

    engine.solvers.plant.DriveBusModel()

    A shared drive bus: sustained sag under a coincident load step, and the regenerative surge of a stop.

    Sag Delta V = Delta I R_bus against the converter lockout; the step current that would spend the depleted pack’s headroom is (V_low - V_uvlo) / R_bus. A stop from speed v returns a share of (1/2) m v^2; into the bus capacitance alone, V_final = sqrt(V_full^2 + 2 E / C). Speed falls linearly at constant deceleration, so regenerated power falls linearly from 2 E / t_stop, and a chopper resistor at the clamp must satisfy R <= V_clamp^2 / P_peak.

    Name Type Description
    DriveBusResult Bus voltages in V, currents in A, energies in J, stop time in ms, peak power in W, and resistor bound in ohm.
    Notes

    Equation: Compute current = compute_power/(converter_efficiency*nominal); sag = step_current*bus_resistance. Recovered energy E = regen_fraction*mass*speed^2/2 gives capacitor-only endpoint sqrt(full^2+2*E/capacitance). Stop duration = speed/deceleration, peak regenerative power = 2*E/stop_duration, and resistor ceiling = clamp^2/peak_power.

    Assumptions: Constant deceleration, resistive sustained sag, and stated energy-recovery fraction.

    Excludes: Inductive transients, battery absorption, and chopper switching dynamics.

    References

    Derivation: Ohm’s law gives sustained sag. Equating recovered kinetic energy to the increase in capacitor energy gives the endpoint voltage. Constant deceleration makes recovery power triangular in time, so its peak is twice its mean. This treats the capacitor-only case separately from battery absorption.

True

    ExponentialRareEventModel

    engine.solvers.plant.ExponentialRareEventModel()

    One rare exponential tail estimated by plain Monte Carlo, a zero-failure campaign, and cross-entropy importance sampling (added 2026-10-20).

    The operational variable is exponential with mean; failure is a draw past threshold, so p = exp(-threshold / mean). Plain Monte Carlo needs (1 - p) / (p r^2) runs for relative error r; a zero-failure campaign needs ceil(ln(1 - C) / ln(1 - p)) clean runs to bound p. The cross-entropy method with elite_share reaches the threshold in a few levels; its exponential proposal gives the per-draw relative variance, the weighted runs for r, the share of proposal draws that fail, and the effective sample size.

    elite_share,
    relative_error,
    confidence,

    One rare exponential tail estimated by plain Monte Carlo, a zero-failure campaign, and cross-entropy importance sampling (added 2026-10-20).

    Parameters
    Name Type Description Default
    threshold Quantity Positive failure threshold, in the same units as mean. required
    mean Quantity Positive operational exponential mean. required
    elite_share float Cross-entropy elite fraction in (0, 1). required
    relative_error float Positive target relative standard error. required
    confidence float One-sided confidence level in (0, 1). required
    Returns
    Name Type Description
    ExponentialRareEventResult Analytic failure probabilities, dimensionless variances, effective counts, and proposal mean in the input units.
    Notes

    Equation: Failure probability p = exp(-threshold/mean). Plain Monte Carlo requires (1-p)/(p*relative_error^2) draws; importance sampling requires relative_variance/relative_error^2. Proposal means and variances come from the analytic exponential cross-entropy and importance-sampling helpers.

    Assumptions: Exponential operational and proposal families with analytic importance weights.

    Excludes: Empirical sampling, distribution misspecification, and device measurements.

    References

    Derivation: The exponential survival function gives p. Bernoulli variance divided by squared target absolute error gives the ordinary sample budget. Applying the same variance-to-error calculation to likelihood-weighted draws yields the importance budget; see mlsysim.physics.statistics.calc_importance_sampling_exponential and calc_cross_entropy_exponential_proposal.

    Examples

>>> ExponentialRareEventModel().solve(Q("5 s"), Q("1 s"), 0.1, 0.1, 0.95).failure_probability < 1
True

    FreshnessProfileModel

    engine.solvers.plant.FreshnessProfileModel()

    A moving target’s freshness deadline against a capture-to-onset age profile.

    The deadline is the tolerance left after the initial error, divided by the target speed: Delta t_fresh = (r_tol - e_0) / v. Stage percentiles are summed per percentile; the target’s travel at the median chain and at the system tail age is compared with the allowed error.

    Parameters
    Name Type Description Default

    tolerance Quantity Allowed position error (m). required
    initial_error Quantity Position error before motion (m). required
    stages Sequence[Tuple[str, Quantity, Quantity, Quantity]] Sequence of (name, median, p99, maximum), with times in seconds. required

    Returns

True

    GearRatioCostModel

    engine.solvers.plant.GearRatioCostModel()

    Holding heat and reflected inertia of one motor holding one joint torque, per gear ratio.

    Motor torque tau_m = tau_out / (eta N); copper loss (tau_m / K_m)^2 with K_m = K_t / sqrt(R_loss); reflected inertia N^2 J_in. Their product is tau_out^2 J_in / (eta^2 K_m^2), independent of N.

    Holding heat and reflected inertia of one motor holding one joint torque, per gear ratio.

    Parameters
    Name Type Description Default
    motor object Motor specification with torque constant, peak torque, and rated torque. required
    loss_resistance Quantity Positive equivalent copper-loss resistance (ohm). required
    input_inertia Quantity Positive input-side inertia (kg*m^2). required
    output_torque Quantity Required joint holding torque (N*m). required
    gear_efficiency float Transmission efficiency in (0, 1]. required
    ratios Iterable[int] Iterable of positive integer reduction ratios. required
    Returns
    Name Type Description
    GearRatioCostResult Per-ratio dictionaries of torque (Nm), copper loss (W), and reflected inertia (kgm^2).
    Notes

    Equation: For reduction N, motor torque is output_torque/(gear_efficiency*N), motor constant Km = torque_constant/sqrt(loss_resistance), copper loss = (motor_torque/Km)^2, and reflected inertia = N^2*input_inertia.

    Assumptions: Constant torque constant, loss resistance, and efficiency across ratios.

    Excludes: Motion losses, gear mass, and temperature feedback.

    References

    Derivation: Combining torque = Kt*current with Joule loss current^2*R gives the torque-squared loss expression. Reflection increases inertia quadratically while required motor torque decreases inversely with reduction; their loss-inertia product therefore cancels N under fixed efficiency.

    GearedRotorModel

    engine.solvers.plant.GearedRotorModel()

    Reflected rotor inertia N^2 J_rotor, sized as a solid flywheel, and the inertia match.

    A solid disk of radius r has J = m r^2 / 2, so m = 2 J / r^2. Joint acceleration for a fixed motor torque peaks at N* = sqrt(J_load / J_rotor); at N it is 2x / (1 + x^2) of that peak, x = N / N*.

    Reflected rotor inertia N^2 J_rotor, sized as a solid flywheel, and the inertia match.

    Parameters
    Name Type Description Default
    gear_ratio float Positive output reduction ratio. required
    rotor_mass Quantity Positive rotor mass (kg). required
    rotor_inertia Quantity Positive rotor inertia (kg*m^2). required
    flywheel_radius Quantity Positive equivalent solid-disk radius (m). required
    load_inertia Quantity Positive output load inertia (kg*m^2). required
    Returns
    Name Type Description
    GearedRotorResult Reflected inertia in kg*m^2, equivalent mass in kg, radius in mm, and dimensionless response share.
    Notes

    Equation: Reflected inertia is gear_ratio^2*rotor_inertia. Equivalent disk mass is 2*reflected_inertia/flywheel_radius^2. Matched ratio Nstar = sqrt(load_inertia/rotor_inertia); normalized acceleration is 2*x/(1+x^2), x = gear_ratio/Nstar.

    Assumptions: Ideal rigid transmission and solid-disk equivalent flywheel.

    Excludes: Gear compliance, friction, and efficiency losses.

    References

    Derivation: Conservation of rotational kinetic energy reflects inertia through the square of the speed ratio. The disk equivalent uses J = m*r^2/2. Maximizing acceleration at fixed motor torque over reduction ratio gives the inertia match; see mlsysim.physics.motors.calc_inertia_matched_ratio.

>>> GearedRotorModel().solve(10, Q("1 kg"), Q("0.01 kg*m^2"), Q("0.1 m"), Q("1 kg*m^2")).reflected_inertia.magnitude > 0
True

    HubDriveElectricalModel

    engine.solvers.plant.HubDriveElectricalModel()

    Electrical time constant, voltage-limited current ramp, and phase-short braking peak of a hub drive.

    tau_e = L / R (line quantities, the same ratio as per phase for a star winding); at stall the back-EMF is zero, so the full bus voltage ramps the current at V / L: t = L I / V. Shorted windings brake hardest where the winding reactance equals its resistance: omega_e = R / L, which is omega_e / p at the wheel for p pole pairs. The same R / L, divided by 2 pi, is the winding’s current pole in hertz.

    StallDeratingModel

    engine.solvers.plant.StallDeratingModel()

    Steady stall temperature with copper’s resistance feedback, and the hold the winding can sustain.

    Steady state: dT = I^2 R_0 [1 + alpha (T_amb - T_0 + dT)] theta, linear in dT, so dT = c / (1 - g) with loop gain g = I^2 R_0 theta alpha (runaway if g >= 1). The sustainable loss at the limit is (T_limit - T_amb) / theta at the hot resistance R(T_limit).

    Notes

    Equation: Motor current I = hold_torque/(gear_efficiency*gear_ratio*torque_constant). With copper coefficient alpha, cold resistance R0, and thermal resistance theta, feedback gain g = I^2*R0*theta*alpha. Steady rise is I^2*R0*theta*(1+alpha*(ambient-T0))/(1-g).     Excludes: Nonlinear heat transfer and runaway transient dynamics; algebraic output above unit gain is not a stable equilibrium.

    Derivation: Substitute the linear copper resistance-temperature relation into steady Joule heating and collect terms in temperature rise.     ZeroFailureModel

    engine.solvers.plant.ZeroFailureModel()

    Upper bound on the per-trial failure rate after a failure-free campaign.

    Poisson (rule of three):  p_upper = -ln(1 - C) / n
exact binomial:           p_upper = 1 - (1 - C)^(1/n)

    With target_rate, also the clean trials that bound the rate at the target: ceil(ln(1 - C) / ln(1 - target)), and its rule-of-three estimate -ln(1 - C) / target (exact form and target added 2026-10-20).

    Methods

    Name Description
    solve Upper bound on the per-trial failure rate after a failure-free campaign.
    solve

    trials,
    confidence,
    target_rate=None,
)

    Upper bound on the per-trial failure rate after a failure-free campaign.

    Parameters
    Name Type Description Default
    trials int Positive number of independent failure-free trials. required
    confidence float One-sided confidence level in (0, 1). required
    target_rate Optional[float] Optional target per-trial failure probability in (0, 1). None
    Returns
    Name Type Description
    ZeroFailureResult Dimensionless approximate/exact failure bounds and trial counts; optional target counts are None when no target is supplied.
    Notes

    Equation: For n trials and confidence C, approximate upper failure probability is -ln(1-C)/n; exact upper probability is 1-(1-C)^(1/n). A target p requires ceil(ln(1-C)/ln(1-p)) failure-free trials.

    Assumptions: Independent identically distributed Bernoulli trials; approximate rate uses the zero-event Poisson bound.

    Excludes: Nonstationarity, correlated failures, and proof of absence of failures.

    References

    Derivation: For independent Bernoulli trials, the probability of zero failures is (1-p)^n. Invert this probability at tail mass 1-C to obtain the exact one-sided bound. Replacing ln(1-p) by -p yields the Poisson approximation; see mlsysim.physics.robotics.assurance.calc_zero_failure_sample_size.

    Examples
    >>> from mlsysim.core.units import Q_ as Q
>>> ZeroFailureModel().solve(100, 0.95).rate_upper_exact < 1
True
