    engine.solvers.supervision

    engine.solvers.supervision

    Responsible physical AI solvers: a detection gap in meters and joules, one assistant’s queue.

    Domain implementations behind mlsysim.solvers (the public import path, derived from engine.solvers.__init__). The equations live in physics/statistics.py and physics/serving.py; these models compose them for one stated machine and site, so a chapter, a slide deck, and a lab read the same arithmetic (added 2026-10-20).

    DetectionShortfallModel

    engine.solvers.supervision.DetectionShortfallModel()

    A stop sized for the best-detected group, met by groups the detector sees less often.

    Each group needs N = ceil(ln p_miss / ln(1 - p_frame)) consecutive frames before detection counts. A group needing Delta N more frames than the reference loses Delta d = v T_frame Delta N before braking begins. The reference stop sheds all of v^2 just as it reaches the person, so the late stop arrives with v_impact = sqrt(2 a Delta d) and E = m a Delta d, valid while Delta d stays below the braking travel v^2 / (2 a).

    SupervisorQueueModel

    engine.solvers.supervision.SupervisorQueueModel()

    One remote assistant serving a fleet, as an M/M/1 queue.

    Requests arrive at lambda = N r (N machines, r requests per machine-hour) and each holds the assistant for a mean s: utilization rho = lambda s, mean wait W_q = rho s / (1 - rho) (the M/G/1 wait ratio with exponential service), and the 99th-percentile wait from the Erlang C tail with one server.
