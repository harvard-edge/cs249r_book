calc_arcsine_two_arm_sample_size

physics.statistics.calc_arcsine_two_arm_sample_size(
    effect_h,
    alpha=0.05,
    power=0.8,
)

Runs per arm to detect Cohen’s h two-sided at alpha with power.

Each arcsine-transformed fraction has variance 1/n, so a difference of two arms has variance 2/n: n = ceil(2 ((z_{1-a/2} + z_power) / h)^2) (Cohen 1988, Table 6.4.1 lists 392 per arm at h = 0.2).

physics.statistics.calc_behavior_cloning_cost_bound(
    horizon_steps,
    per_step_error,
)

Worst-case excess cost of behavioral cloning over horizon_steps: S^2 eps.

Ross and Bagnell (2010), Theorem 2.1: a policy trained only on the demonstrator’s states compounds a per-step error eps quadratically.

calc_cdf_quantile

physics.statistics.calc_cdf_quantile(values, cumulative, fraction)

First value whose empirical cumulative fraction reaches fraction.

values ascend with cumulative (a released CDF); past the end the last value is returned.

calc_chance_agreement

physics.statistics.calc_chance_agreement(class_shares)

Agreement two independent annotators reach by chance: sum_k s_k ** 2.

class_shares is each annotator’s label mix (fractions summing to 1); both annotators are assumed to share it.

calc_chi2_gate

physics.statistics.calc_chi2_gate(confidence, dof)

Chi-square quantile that a consistent statistic with dof degrees of freedom stays below with probability confidence (added 2026-10-20).

A validation gate rejects an innovation whose normalized squared value (NIS) exceeds this threshold.

Source: Bar-Shalom, Li, and Kirubarajan, Estimation with Applications to Tracking and Navigation (2001), Sec. 5.4.

calc_chi2_mean_band

physics.statistics.calc_chi2_mean_band(n_samples, dof, confidence)

Two-sided acceptance band for the mean of n_samples consistent chi-square statistics (added 2026-10-20).

The sum of N independent NEES (or NIS) values of dimension n is chi-square with N n degrees of freedom; dividing its central confidence interval by N gives the band the sample mean must fall in.

Source: Bar-Shalom, Li, and Kirubarajan (2001), Sec. 5.4.2.

calc_chi_square_quantile

physics.statistics.calc_chi_square_quantile(degrees_of_freedom, coverage)

Quantile of the chi-square distribution: the squared Mahalanobis radius of a Gaussian confidence region holding probability coverage in degrees_of_freedom dimensions (added 2026-10-20).

A point of a k-dimensional Gaussian lies inside the region (x - mu)^T Sigma^-1 (x - mu) <= r^2 with probability coverage when r^2 is this quantile; the region’s principal semi-axes are r sigma_i. For k = 3 and 0.95 the quantile is about 7.815.

Source: the chi-square distribution of a sum of k squared standard normals (NIST/SEMATECH e-Handbook of Statistical Methods, Sec. 1.3.6.6.6).

calc_clopper_pearson_interval

physics.statistics.calc_clopper_pearson_interval(
    successes,
    trials,
    confidence=0.95,
)

Exact two-sided Clopper-Pearson interval for successes out of trials.

Equation (beta quantiles, alpha = 1 - confidence): lower = B^{-1}(alpha/2; k, n - k + 1) (0 when k = 0) upper = B^{-1}(1 - alpha/2; k + 1, n - k) (1 when k = n)

Source: Clopper and Pearson, “The Use of Confidence or Fiducial Limits Illustrated in the Case of the Binomial,” Biometrika 26(4), 1934.

calc_cohens_h

physics.statistics.calc_cohens_h(p_high, p_low)

Cohen’s effect size for two proportions: h = 2 asin sqrt(p1) - 2 asin sqrt(p2) (Cohen 1988, ch. 6).

calc_cohens_kappa

physics.statistics.calc_cohens_kappa(observed_agreement, chance_agreement)

Cohen’s kappa: agreement beyond chance, (p_o - p_e) / (1 - p_e) (Cohen 1960).

calc_conjunctive_confidence

physics.statistics.calc_conjunctive_confidence(premise_confidences)

Confidence in a claim that needs every one of several independent premises.

Equation: P(claim) = prod_i p_i

The conjunction is no stronger than its weakest premise and, with more than one premise below 1, strictly weaker.

Source: probability of the intersection of independent events, as applied to conjunctive assurance arguments in Bloomfield and Littlewood 2003, “Multi-legged arguments: the impact of diversity upon confidence in dependability arguments” (DSN 2003).

calc_consecutive_detection_frames

physics.statistics.calc_consecutive_detection_frames(
    per_frame_detection,
    all_miss_probability,
)

Consecutive frames a person must be in view before detection may be counted on.

Equation: N = ceil( ln p_miss / ln(1 - p_frame) )

the fewest frames for which the chance of missing the person in every one, (1 - p_frame)^N, is at most all_miss_probability, with misses independent from frame to frame (the best case; correlated misses need more frames). A tolerance of 1e-12 keeps an exact ratio from rounding up.

calc_cross_entropy_exponential_proposal

physics.statistics.calc_cross_entropy_exponential_proposal(
    threshold,
    operational_mean,
    elite_share,
)

Expected (large-sample) cross-entropy iteration for an exponential tail.

From q_0 = p = Exp(m0), each round sets the level to the (1 - beta) quantile of the current proposal, level = -m_k ln(beta) (capped at the threshold), and refits the proposal mean to the likelihood-weighted elite draws; for this family that is E_p[D | D > level] = level + m0. Stops when the level reaches the threshold, so the final mean is threshold + m0.

Returns a dict with levels (list, in the units of threshold), n_levels, and proposal_mean.

Source: Rubinstein and Kroese, The Cross-Entropy Method (Springer, 2004), multilevel rare-event algorithm; the exponential refit is in closed form.

calc_dagger_cost_bound

physics.statistics.calc_dagger_cost_bound(
    horizon_steps,
    per_step_error,
    recoverability=1.0,
)

Worst-case excess cost with expert labels on learner states: u S eps.

Ross, Gordon, and Bagnell (2011), Theorem 3.2: linear in the horizon while the recoverability constant u stays bounded.

calc_effective_sample_size

physics.statistics.calc_effective_sample_size(n_records, lag1_correlation)

Effective number of independent samples in n_records of an AR(1) series.

N_eff = N (1 - rho) / (1 + rho) for estimating the mean of a series whose adjacent records have lag-one correlation rho (Thiebaux and Zwiers 1984).

calc_equal_n_for_z

physics.statistics.calc_equal_n_for_z(rate_a, rate_b, z_critical)

Per-group sample size at which the pooled two-proportion z of a fixed gap reaches z_critical.

With equal groups, z = gap / sqrt(2 p (1 - p) / n), so n = 2 p (1 - p) (z_critical / gap)^2 with p the mean of the two rates.

calc_expected_calibration_error

physics.statistics.calc_expected_calibration_error(bins)

Expected calibration error of binned predictions: sum |B_i| / n * |acc_i - conf_i|.

bins is a sequence of (count, confidence, accuracy); the weight of each bin is its share of the predictions (Pakdaman Naeini et al. 2015; Guo et al. 2017, eq. 3).

calc_exponential_decay_rate

physics.statistics.calc_exponential_decay_rate(initial, later, elapsed)

Rate gamma of A(t) = A0 exp(-gamma t) through two readings: gamma = ln(A0 / A1) / t. elapsed may be a Quantity (the rate is then per its unit) or a plain number.

calc_fisher_exact_two_sided

physics.statistics.calc_fisher_exact_two_sided(a, b, c, d)

Two-sided Fisher exact p for the 2x2 table [[a, b], [c, d]] (rows are the two arms).

Sums the hypergeometric probabilities of every table with the observed margins that is no more probable than the observed one. Source: Fisher, Statistical Methods for Research Workers (1934 ed.), sec. 21.02.

calc_gaussian_kl

physics.statistics.calc_gaussian_kl(mean_p, sd_p, mean_q, sd_q)

KL divergence KL(P || Q) between two normal distributions, in nats.

calc_gaussian_kl_terms

physics.statistics.calc_gaussian_kl_terms(mean_p, sd_p, mean_q, sd_q)

The two terms of KL(P || Q) for normals P and Q.

KL = ln(sd_q / sd_p) + (sd_p^2 + (mean_p - mean_q)^2) / (2 sd_q^2) - 1/2. Returns (log_term, ratio_numerator, ratio_denominator) so a worked example can show each piece; calc_gaussian_kl adds them.

calc_importance_sampling_exponential

physics.statistics.calc_importance_sampling_exponential(
    threshold,
    operational_mean,
    proposal_mean,
)

Importance-sampling statistics for an exponential tail with an exponential proposal.

Operational model p = Exp(mean m0), failure when D > gamma, proposal q = Exp(mean m_q) with likelihood ratio w = p/q. Writing lam = 1/m0 and eta = 1/m_q (eta < 2 lam so the second moment is finite):

P_F                 = exp(-lam gamma)
E_q[w^2 1{D>gamma}] = lam^2 / (eta (2 lam - eta)) * exp(-(2 lam - eta) gamma)
relative variance   = E_q[w^2 1{D>gamma}] / P_F^2 - 1      (per draw)
ESS per draw        = E_q[w]^2 / E_q[w^2] = eta (2 lam - eta) / lam^2
P_q(D > gamma)      = exp(-eta gamma)

Draws for a relative standard error r are relative_variance / r**2. threshold, operational_mean, and proposal_mean are Pint quantities of one dimension (or plain floats in one unit).

Source: likelihood-ratio estimator, its second moment, and the effective sample size (sum w)^2 / sum w^2 from Owen 2013, ch. 9; the exponential closed forms follow by integrating those expressions.

calc_jensen_shannon_divergence

physics.statistics.calc_jensen_shannon_divergence(p, q)

Jensen-Shannon divergence between two aligned distributions, in nats.

JS = KL(p || m) / 2 + KL(q || m) / 2 with m = (p + q) / 2. It is symmetric and bounded by ln 2, which two distributions with disjoint support reach. Source: Lin, “Divergence Measures Based on the Shannon Entropy,” IEEE Trans. Inf. Theory 37(1), 1991.

calc_ks_coefficient

physics.statistics.calc_ks_coefficient(significance)

Large-sample two-sample K-S coefficient c(alpha) = sqrt(-ln(alpha / 2) / 2).

About 1.36 at 0.05 (Ops.Monitoring.KsTestCoefficient) and 1.63 at 0.01; calc_ks_critical_value scales it by the two sample sizes.

calc_ks_critical_value

physics.statistics.calc_ks_critical_value(coefficient, n_reference, n_current)

Large-sample two-sample Kolmogorov-Smirnov critical value.

D_crit = c * sqrt((n_0 + n_t) / (n_0 * n_t)), where c is the coefficient for the chosen significance level (1.36 at 0.05, Ops.Monitoring.KsTestCoefficient).

calc_ks_normal_location_shift

physics.statistics.calc_ks_normal_location_shift(shift_sd)

K-S distance between two equal-variance normals whose means differ by shift_sd sds.

The CDF gap is largest midway between the means: 2 * Phi(shift_sd / 2) - 1, which equals erf(shift_sd / (2 * sqrt(2))).

calc_linf_corner_l2

physics.statistics.calc_linf_corner_l2(linf_budget, coordinates)

Euclidean length of a corner of the l-infinity ball of radius linf_budget in coordinates dimensions.

calc_mcnemar_exact_two_sided

physics.statistics.calc_mcnemar_exact_two_sided(first_only, second_only)

Exact two-sided McNemar p from the discordant counts (McNemar 1947).

Conditional on d = first_only + second_only discordant pairs, wins are Binomial(d, 1/2) under equal marginals: p = min(1, 2 sum_{j <= min(b, c)} C(d, j) 2^-d); 1 when d = 0.

calc_mcnemar_max_discordant

physics.statistics.calc_mcnemar_max_discordant(net_gap, critical)

Largest disagreement count b + c at which McNemar’s statistic still exceeds critical.

The statistic (no continuity correction) is (b - c)^2 / (b + c); with the net gap b - c fixed, it exceeds the 1-dof chi-square critical value only when b + c <= floor(gap^2 / critical) (McNemar 1947).

calc_mean_half_width

physics.statistics.calc_mean_half_width(sd, n_samples, confidence)

Half-width of a confidence interval on a mean of n_samples values: t_{n-1} sd / sqrt(n).

calc_monte_carlo_sample_size

physics.statistics.calc_monte_carlo_sample_size(
    failure_probability,
    relative_error,
)

Plain Monte Carlo draws needed to estimate a probability to a relative error.

Equation: N = (1 - p) / (p * r^2)

The binomial estimator p_hat = k/N has relative standard error sqrt((1 - p) / (N p)); solving for N at a target r gives the count.

Source: Owen, Monte Carlo Theory, Methods and Examples (2013): the variance of a sample mean of Bernoulli draws, as used for rare events in ch. 9.

calc_multilegged_confidence

physics.statistics.calc_multilegged_confidence(leg_confidences)

Confidence in a claim supported by independent legs, any one of which suffices.

calc_two_proportion_sample_size

physics.statistics.calc_two_proportion_sample_size(
    baseline_rate,
    detectable_lift,
    z_alpha=1.96,
    z_beta=0.84,
    pooled=False,
)

Per-arm sample size for a two-proportion A/B test.

Standard normal-approximation power formula: n = 2 * (z_alpha + z_beta)^2 * p(1-p) / delta^2, using the baseline rate’s variance for both arms (a common simplification valid for small lifts). Defaults correspond to a two-sided 5% significance level (z = 1.96) and 80% power (z = 0.84).

Parameters

Name Type Description Default
baseline_rate float Control-arm conversion rate p in (0, 1). required
detectable_lift float Minimum absolute difference in rates to detect (same 0-1 scale as baseline_rate, e.g. 0.01 for one percentage point). Must be > 0. required
z_alpha float Normal quantile for the significance level (1.96 = two-sided 0.05). 1.96
z_beta float Normal quantile for power (0.84 = 80% power). 0.84
pooled bool When True, use the pooled two-proportion form, which carries the variance of both arms rather than reusing the baseline’s for each: n = (z_alpha * sqrt(2 * p_bar * q_bar) + z_beta * sqrt(p1*q1 + p2*q2))^2 / delta^2 where p_bar is the mean of the two rates. This is the textbook form and the one the book’s own appendix displays. It is not the default because the simplified form above is already in use and its results are quoted in print; pass pooled=True where the pooled form is the one being taught. False

Returns

Name Type Description
float Required sample size per arm (unrounded; callers should ceil).

calc_wilson_interval

physics.statistics.calc_wilson_interval(successes, trials, z_critical)

Wilson score interval for a binomial proportion (Wilson 1927), clipped to [0, 1].

center = (x + z^2/2) / (n + z^2)
half   = z / (n + z^2) * sqrt(x (n - x) / n + z^2 / 4)

The variance uses the hypothesized rate, so the interval keeps a nonzero width at x = 0 and x = n and never leaves [0, 1].
