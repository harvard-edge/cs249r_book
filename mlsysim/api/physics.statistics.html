calc_arcsine_two_arm_sample_size

physics.statistics.calc_arcsine_two_arm_sample_size(
    effect_h,
    alpha=0.05,
    power=0.8,
)

Plan equal arm sizes using an arcsine effect size.

Parameters

Name Type Description Default
effect_h float Nonzero dimensionless Cohen h effect size; its sign does not affect sample size. required
alpha float Two-sided significance probability in (0, 1); default 0.05. 0.05
power float Target power probability in (0, 1); default 0.80. 0.8

Returns

Name Type Description
int Required observations per arm, rounded upward.

Notes

Equation: n = ceil(2*((Phi**(-1)(1-alpha/2)+Phi**(-1)(power))/h)**2).

Assumptions: Independent equal-size arms and the large-sample variance approximation for transformed proportions.

Excludes: Exact binomial power, unequal allocation, multiple testing, and input-domain validation.

References

Cohen (1988), Statistical Power Analysis for the Behavioral Sciences, chapter 6. Derivation: Each transformed rate has variance 1/n; solve the two-arm normal power relation with variance 2/n.

Examples

calc_consecutive_detection_frames

physics.statistics.calc_consecutive_detection_frames(
    per_frame_detection,
    all_miss_probability,
)

Find the frame count for an all-miss probability target.

Consecutive frames a person must be in view before detection may be counted on.

Equation: N = ceil( ln p_miss / ln(1 - p_frame) )

the fewest frames for which the chance of missing the person in every one, (1 - p_frame)^N, is at most all_miss_probability, with misses independent from frame to frame (the best case; correlated misses need more frames). A tolerance of 1e-12 keeps an exact ratio from rounding up.

Parameters

Name Type Description Default
per_frame_detection float Detection probability per independent frame, in (0, 1). required
all_miss_probability float Maximum all-miss probability in (0, 1). required

Returns

Name Type Description
int Minimum frame count under the independent-miss model.

Notes

Equation: N = ceil(log(all_miss_probability)/log(1-per_frame_detection)-1e-12).

Assumptions: Independent frame misses with a constant detection probability.

Excludes: Temporal correlation and uncertainty in detector performance.

References

Derivation: Multiply independent miss probabilities and invert the geometric decay.

Examples

>>> calc_consecutive_detection_frames(0.5, 0.25) == 2
True

calc_cross_entropy_exponential_proposal

physics.statistics.calc_cross_entropy_exponential_proposal(
    threshold,
    operational_mean,
    elite_share,
)

Trace population cross-entropy updates for an exponential tail.

Parameters

Name Type Description Default
threshold float or Quantity Positive target failure threshold gamma. required
operational_mean float or Quantity Positive operational mean m0, in threshold units. required
elite_share float Elite proposal fraction beta in (0, 1). required

Returns

Name Type Description
dict Levels contains thresholds in input units, n_levels is their count, and proposal_mean is the final mean in input units.

Notes

Equation: level_k = min(gamma, -m_k*log(beta)); m_(k+1) = level_k + m0, until level_k reaches gamma.

Assumptions: Population expectations replace empirical elites; the initial proposal mean equals the operational mean.

Excludes: Sampling variability, weight degeneracy, finite-sample stopping, and non-exponential families.

From q_0 = p = Exp(m0), each round sets the level to the (1 - beta) quantile of the current proposal, level = -m_k ln(beta) (capped at the threshold), and refits the proposal mean to the likelihood-weighted elite draws; for this family that is E_p[D | D > level] = level + m0. Stops when the level reaches the threshold, so the final mean is threshold + m0.

Returns a dict with levels (list, in the units of threshold), n_levels, and proposal_mean.

Source: Rubinstein and Kroese, The Cross-Entropy Method (Springer, 2004), multilevel rare-event algorithm; the exponential refit is in closed form.

References

Derivation: exponential memorylessness gives E[X | X > level] = level + m0; the proposal quantile supplies the next level. Rubinstein and Kroese (2004), The Cross-Entropy Method, motivates multilevel adaptation.

Examples

>>> result = calc_cross_entropy_exponential_proposal(2.0, 1.0, 0.5)
>>> result["levels"][-1] == 2.0 and result["proposal_mean"] == 3.0
True

Parameters

physics.statistics.calc_within_task_variance(mean_rate, between_task_variance)

Recover within-task Bernoulli variance from task heterogeneity.

Mean within-task run variance E[p_i (1 - p_i)] = mean (1 - mean) - Var(p_i).

Parameters

Name Type Description Default
mean_rate float Mean task probability in [0, 1], dimensionless. required
between_task_variance float Nonnegative variance of task probabilities, dimensionless. required

Returns

Name Type Description
float Dimensionless within-task outcome variance.

Notes

Equation: E[p_i(1-p_i)] = mean_rate*(1-mean_rate)-between_task_variance.

Assumptions: A valid mixture of Bernoulli task probabilities.

Excludes: Estimation uncertainty or correction of inconsistent variance inputs.

References

Derivation: Conditional on task i, a Bernoulli outcome has variance p_i*(1-p_i). Averaging over tasks gives E[p_i]-E[p_i^2]. Substitute E[p_i^2] = Var(p_i)+E[p_i]^2 to obtain the implemented decomposition.
