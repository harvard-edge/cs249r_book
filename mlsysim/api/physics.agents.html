calc_append_only_context

physics.agents.calc_append_only_context(initial_tokens, tokens_per_turn, turns)

Count final and cumulative input tokens in an append-only trajectory.

Parameters

Name Type Description Default
initial_tokens Quantity or int Nonnegative tokens in the first request. required
tokens_per_turn Quantity or int Nonnegative tokens appended between successive requests, using the same units as initial_tokens. required
turns int Positive number of requests in the trajectory. required

Returns

Name Type Description
tuple Last-request token count and cumulative input-token count, retaining input units.

Notes

Equation: last = s0 + delta (H - 1); total = H s0 + delta H (H - 1) / 2.

Assumptions: Every request resends the full earlier context; append size is constant.

Excludes: Prefix caching, compaction, request-window limits, and output-token billing.

References

Derivation: Sum the arithmetic progression s0, s0 + delta, …, s0 + (H - 1) delta.

Examples

>>> last, total = calc_append_only_context(10, 2, 3)
>>> (last, total) == (10 + 2 * 2, sum([10, 12, 14]))
True

calc_break_even_acceptance

physics.agents.calc_break_even_acceptance(acceptance_probability, cut, share)

Find the acceptance rate equivalent to a component price cut.

Parameters

Name Type Description Default
acceptance_probability float Current acceptance probability in [0, 1]. required
cut float Fractional reduction of the selected cost component in [0, 1]. required
share float Selected component share of total attempt cost in [0, 1]; cut * share must be below 1. required

Returns

Name Type Description
float Required acceptance probability; a value above 1 means the target is unattainable.

Notes

Equation: p_new = p_accept / (1 - cut * share).

Assumptions: The price cut changes cost but not acceptance; raising acceptance leaves attempt cost unchanged.

Excludes: Interactions between quality and price, and clipping an unattainable target to 1.

References

Derivation: Equate C / p_new with C (1 - cut share) / p_accept and cancel C.

Examples

>>> calc_break_even_acceptance(0.5, cut=0.5, share=0.5) == 0.5 / 0.75
True

Calculate elapsed cleanup time under unlimited parallelism.

Parameters

Parameters

Name Type Description Default

Returns

Name Type Description
float Long-run average admitted calls per scheduling round.

calc_expected_max_std_normal

physics.agents.calc_expected_max_std_normal(n, lo=-10.0, hi=10.0, steps=40000)

Integrate the expected maximum of independent standard normals.

Parameters

Name Type Description Default
n int Positive number of independent standard-normal draws. required
lo float Lower integration limit in standard deviations; default -10. -10.0
hi float Upper integration limit greater than lo; default 10. 10.0
steps int Positive trapezoid count; default 40000. 40000

calc_first_horizon_below

physics.agents.calc_first_horizon_below(step_success, threshold)

Find the first whole horizon below a success threshold.

Parameters

Name Type Description Default
step_success float Per-step success probability strictly between 0 and 1. required
threshold float Task success threshold strictly between 0 and 1. required

Returns

Name Type Description
int First positive whole-step horizon with task success below threshold.

Notes

Equation: n = floor(log(threshold) / log(step_success)) + 1.

Assumptions: Identical independent step success and an exact strict inequality.

Derivation: Solve p ** n < threshold for n; log(p) is negative, so n must exceed the log ratio.

calc_nucleus

Select and renormalize the top-p probability nucleus.

Returns

Name Type Description

calc_pass_at_k_unbiased

physics.agents.calc_pass_at_k_unbiased(samples, passing, k)

Estimate the probability that a size-k sample contains a pass.

Parameters

Name Type Description Default
samples int Positive count n of graded samples. required
passing int Passing sample count c in [0, n]. required
k int Subset size in [1, n]. required

Returns

Name Type Description
float Unbiased estimate of the probability at least one of k draws passes.

Notes

Equation: pass_at_k = 1 - C(n - c, k) / C(n, k), or 1 if n - c < k.

Assumptions: Exchangeable independent draws from a fixed task distribution.

Excludes: Dependence among samples, uncertainty intervals, and changing graders.

References

Derivation: Count all-failing subsets among all size-k subsets and subtract their fraction from one; this is the combinatorial estimator described by Chen et al. (2021).

Chen et al. (2021), “Evaluating Large Language Models Trained on Code.” https://arxiv.org/abs/2107.03374 (bibliography key: chen2021evaluating).

Examples

>>> calc_pass_at_k_unbiased(4, 2, 1) == 0.5
True

Parameters

Name Type Description Default

k int Subset size in [1, n]. required

Returns

Name Type Description
float Unbiased estimate of the probability that all k draws pass.

calc_pruned_tree_nodes

physics.agents.calc_pruned_tree_nodes(branching, rejection_rate, depth)

Count proposed search nodes with and without independent pruning.

Parameters

Name Type Description Default
branching int Nonnegative child count proposed per retained node. required
rejection_rate float Independent rejection probability in [0, 1]. required
depth int Nonnegative number of child levels, excluding the root. required

Returns

Name Type Description
tuple Unpruned node count and expected proposed node count with pruning; neither includes the root.

Notes

Equation: unpruned = sum_d b ** d; pruned = sum_d b [b (1 - r)] ** (d - 1).

Assumptions: Constant branching, independent rejection, and no expansion of rejected nodes.

>>> full == pruned
True

calc_repair_break_even

physics.agents.calc_repair_break_even(repair_cost, fallback_cost)

Find the repair success rate that breaks even with fallback.

Parameters

Name Type Description Default
repair_cost Quantity or float Nonnegative cost of one repair attempt. required
fallback_cost Quantity or float Positive fallback cost in the same units as repair_cost. required

Returns

Name Type Description
float Repair success probability at equal expected cost; above one means repair cannot win on this axis.

Notes

Equation: p_star = C_repair / C_fallback.

Assumptions: A failed repair leaves the fallback available at unchanged cost.

Excludes: Irreversible damage, repair repetitions, and joint optimization across unlike units.

References

Derivation: Equate C_repair + (1 - p) C_fallback with C_fallback, then solve for p.
