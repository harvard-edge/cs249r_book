    engine.solvers.cost_accounting

    engine.solvers.cost_accounting

    Agent cost-accounting solvers: what one accepted task costs, and what each lever buys (added 2026-10-20).

    Domain implementations behind mlsysim.solvers. Each model is arithmetic on stated inputs: the fitted fall of a fixed capability’s price, cost against score on long-horizon trials, a cohort of one-attempt tasks under a tariff, prefix-cache bills and the payback of one compaction, retry policies under independent attempts, a serial episode under Amdahl’s law and speculative decoding, a tiered model cascade under one gate, admission against a token quota, Kingman’s queue price, renting tokens against owning capacity, a conserved budget across children, architectures with a human fallback, the payback of a one-time adaptation, per-workload levers on cost per accepted task, measured coverage against independent trials, and one server swept across concurrency. None models a particular provider’s billing system.

    AdaptationPaybackModel

    engine.solvers.cost_accounting.AdaptationPaybackModel()

    Tasks until a one-time adaptation repays its data, training, and evaluation.

    Each task’s model usage is steps times (input tokens x input price + output tokens x output price); the break-even count is the investment over the per-task saving, and the first whole task that crosses it.

    adapted Mapping[str, float] Adapted mapping with the same keys and units as base. required
    data_cost Quantity One-time data investment, convertible to USD. required
    training_cost Quantity One-time training investment, convertible to USD. required
    evaluation_cost Quantity One-time evaluation investment, convertible to USD. required

    Name Type Description
    AdaptationPaybackResult Step, task, investment, and saving USD quantities; fractional and rounded task break-even counts; payback months and cost shares.
    Notes

>>> r = AdaptationPaybackModel().solve(base, adapted, Q_('1 USD'), Q_('1 USD'), Q_('1 USD'), 1000, 100)
>>> r.payback_months_low > r.payback_months
True

    ArchitectureChoiceModel

    engine.solvers.cost_accounting.ArchitectureChoiceModel()

    Designs priced by automated spend alone and with a human fallback.

    A bounded loop stops at its first accepted turn, so turn j is reached by the share that every earlier turn rejected. Rejected tickets go to a person who resolves a fraction of them; cost per resolved ticket divides the combined spend by combined resolution.

    single_costs Mapping[str, Quantity] Configuration names mapped to per-attempt USD quantities. required
    single_acceptance Mapping[str, float] Configuration names mapped to acceptance probabilities in (0,1]. required
    loop_name str Name for the iterative configuration, distinct from single configurations. required
    turn_cost Quantity Charge per reached loop turn, convertible to USD. required
    turn_acceptance Sequence[float] Conditional probabilities of acceptance on each reached turn. required
    check_cost Quantity Charge for checking each attempt, convertible to USD. required
    human_cost Quantity Fallback human charge per unresolved automated ticket, convertible to USD. required
    human_resolution float Fraction of fallback tickets resolved by a person, in [0,1]. required
    point float Dimensionless fraction of human cost used for point_value. required
    Returns
    Name Type Description
    ArchitectureChoiceResult Per-configuration USD quantity costs, acceptance/resolution fractions, expected loop turns, and period spend and resolved counts.
    Notes

    Equation: reach[j] = product(1-turn_acceptance[:j]); total cost = automated + (1-acceptance)*human_cost; resolved = acceptance+(1-acceptance)*human_resolution.

    Assumptions: Conditional turn acceptance probabilities in [0,1]; positive acceptance and resolution denominators; constant fallback cost.

    Excludes: Quality comparability, correlated human/model mistakes, and queueing delays.

    References

    Derivation: Multiply conditional rejection probabilities to obtain each turn reach share. Weight automated charges by reach, then add human fallback cost for rejected tickets and divide by total automated-plus-human resolution.

    Examples

>>> r = ArchitectureChoiceModel().solve(10, {'single': Q_('1 USD')}, {'single': 0.5}, 'loop', Q_('1 USD'), [0.5, 0.5], Q_('0.1 USD'), Q_('5 USD'), 1.0, 0.01)
>>> r.resolved['loop'] == 1.0
True

    CohortAttemptCostModel

    The attempt costs its turns of model tokens and environment plus one assessment; the cohort cost per accepted task divides every attempt’s cost by the accepted count, and triage charges each rejected attempt.

    CompactionPaybackModel

    engine.solvers.cost_accounting.CompactionPaybackModel()

    One compaction priced against keeping the transcript, under one tariff.

    Compacting at call n_c replaces S tokens of context with a S_c-token summary that costs K output tokens and is resent fresh, so the compacting call costs p_out K + p_in S_c more; every later call reads S - S_c fewer cached tokens. Compaction has paid after n* = 1 + ceil(upfront / per-call saving) calls.

    Methods

    Name Description
    solve Compute when a context summary repays its token bill.

    turns,
    first_prompt,
    appended,
    input_price,
    cached_fraction,
    output_price,
    compact_turn,
    compact_to,
    summary_tokens,
)

    Compute when a context summary repays its token bill.

    Parameters
    Name Type Description Default
    turns int Number of model turns; positive integer. required
    first_prompt int Initial prompt length, in tokens. required
    appended int Tokens appended between consecutive calls. required
    input_price Quantity Fresh input tariff, as a quantity convertible to USD/Mtoken. required
    cached_fraction float Cached-input price divided by fresh-input price, in [0,1]. required
    output_price Quantity Output tariff, as a quantity convertible to USD/Mtoken. required
    compact_turn int One-based compaction call index within the trajectory. required
    compact_to int Summary context length in tokens, smaller than the replaced context. required
    summary_tokens int Generated summary tokens billed at the output tariff. required
    Returns
    Name Type Description
    CompactionPaybackResult Context and remaining-call counts, USD quantity costs and savings, integer break-even call count, and per-horizon net USD floats.
    Notes

    Equation: upfront = p_out*summary_tokens + p_in*compact_to; saving = (context_at_compaction-compact_to)*cached_fraction*p_in; crossing = 1+ceil(upfront/saving).

    Assumptions: The summary preserves the required task state; compact_turn is within the trajectory; positive cached price and positive token reduction.

    Excludes: Changes in answer quality, latency, and later summary regeneration.

    References

    Derivation: The summary generation and first fresh summary read are upfront charges. Each later call avoids the same cached-context bill. Divide upfront cost by this saving, round up, and include the compaction call.

    Examples
    >>> from mlsysim.core.units import Q_
>>> r = CompactionPaybackModel().solve(10, 1000, 10, Q_('1 USD/Mtoken'), 0.5, Q_('2 USD/Mtoken'), 2, 100, 10)
>>> r.per_call_saving > Q_('0 USD')
True

    ConservedBudgetModel

    engine.solvers.cost_accounting.ConservedBudgetModel()

    A root budget kept as settled + reserved + free across two children.

    Granting moves free to reserved; a child that closes settles its charge and returns the rest. A child stopped with a remote operation pending keeps that operation’s enforceable bound reserved until its final bill settles, once per settlement identity however often it is delivered.

    Track settled, reserved, and free budget through child completion.

    Parameters
    Name Type Description Default
    budget int Total nonnegative integer budget in milli-USD. required
    planning int Initial settled planning charge in milli-USD. required
    allocations Sequence[int] Two nonnegative child reservations in milli-USD. required
    settled_children Sequence[int] Two child settled charges in milli-USD. required
    pending int Second child pending reservation in milli-USD. required
    late_charge int Final charge for the pending operation in milli-USD. required
    deliveries int Positive count of repeated deliveries of the final bill; default 2. 2
    Returns
    Name Type Description
    ConservedBudgetResult Ledger states and child balances in integer milli-USD, with settled, reserved, and free components at each transition.
    Notes

    Equation: budget = settled + reserved + free at every transition; duplicate delivery of the same settlement identity is applied once.

    Assumptions: Two child allocations in common integer budget units; charges fit reservations; nonnegative conserved state.

    Excludes: Distributed durability, concurrent ledger races, and remote billing enforcement.

    References

    Derivation: A grant transfers free funds to reservations. Settlement transfers a charge from reserved to settled and refunds the unused reservation. Deduplicating the final bill prevents repeated delivery from spending twice.

    Examples
    >>> from mlsysim.core.units import Q_
>>> r = ConservedBudgetModel().solve(1000, 100, [300, 400], [200, 100], 100, 80)
>>> r.settled_final + r.reserved_final + r.free_final == r.budget
True

    DedicatedBreakEvenModel

    engine.solvers.cost_accounting.DedicatedBreakEvenModel()

    KingmanQueueModel

    engine.solvers.cost_accounting.KingmanQueueModel()

    Kingman’s mean wait for one server at two utilizations, and its holding price.

    E[W] = (c_a^2 + c_s^2) / 2 * rho / (1 - rho) * E[S]; each second of wait holds resources at holding_rate dollars.

    Methods

    Name Description
    solve Estimate mean queue wait and its resource holding cost.
    solve
    engine.solvers.cost_accounting.KingmanQueueModel.solve(
    service,
    arrival_scv,
    service_scv,
    low,
    high,
    holding_rate,
)

    Estimate mean queue wait and its resource holding cost.

    Parameters
    Name Type Description Default
    service Quantity Positive mean service duration, convertible to seconds. required
    arrival_scv float Squared coefficient of variation of interarrival times, nonnegative. required
    service_scv float Squared coefficient of variation of service times, nonnegative. required
    low float Lower utilization in (0,1). required
    high float Higher utilization in (0,1). required
    holding_rate float Holding cost in USD per second of waiting. required
    Returns
    Name Type Description
    KingmanQueueResult Mean wait quantities in service-time units, holding costs as USD floats, and dimensionless variability, utilization, and wait ratios.
    Notes

    Equation: W = service*(arrival_scv+service_scv)/2*rho/(1-rho); holding cost = W_seconds*holding_rate.

    Assumptions: Single-server stationary renewal approximation; positive service and variability; 0 < low, high < 1.

    Excludes: Tail latency, transient overload, and multiple-server scheduling.

    References

    Derivation: The Kingman single-server approximation multiplies mean service time by a variability factor and rho/(1-rho). Convert the resulting wait to seconds before applying the holding tariff. This is an approximation, not an exact queueing identity; see calc_kingman_wait_ratio.

>>> r.wait_high > r.wait_low
True

    ModelCascadeModel

    engine.solvers.cost_accounting.ModelCascadeModel()

    A tiered cascade under one acceptance gate, priced over a completed cohort.

    Every reached tier pays its call and the gate; the cascade’s cost per accepted task divides the whole spend by every tier’s exits. Optionally a harm per false accept at the first tier, whose break-even rate erases the cascade’s saving over the top tier alone.

    Excludes: Unobserved acceptance quality, correlated latency, and asynchronous tier overlap.

    References

    Derivation: Only unresolved tasks reach the next tier. Multiply each tier charge and duration by its reached population, then normalize spend by all accepted exits and elapsed work by all initiated tasks.

    Examples
    >>> from mlsysim.core.units import Q_
>>> r = ModelCascadeModel().solve(10, [1.0, 3.0], 0.1, [1.0, 2.0], 0.1, [5, 4], 9)
>>> r.reached == [10, 5]
True

    PrefixCacheBillModel

    engine.solvers.cost_accounting.PrefixCacheBillModel()

    An append-only trajectory billed at the fresh rate, and with ideal prefix reuse.

    The logical input is H s0 + delta H (H - 1) / 2; ideal reuse bills only s0 + (H - 1) delta at the input rate and the rest at the cached rate, so caching scales the quadratic term down without removing it. A miss on miss_fraction of the eligible prefix bills it at the full rate.

    input_price,
    cached_fraction,
    output_price,
    miss_fraction,
)

    Price append-only prompts with ideal prefix reuse.

    Parameters
    Name Type Description Default
    turns int Number of model turns; positive integer. required
    first_prompt int Initial prompt length, in tokens. required
    appended int Tokens appended between consecutive calls. required
    output_per_turn int Generated tokens per turn. required
    input_price Quantity Fresh input tariff, as a quantity convertible to USD/Mtoken. required
    cached_fraction float Cached-input price divided by fresh-input price, in [0,1]. required
    output_price Quantity Output tariff, as a quantity convertible to USD/Mtoken. required
    miss_fraction float Fraction of reusable prefix charged fresh, in [0,1]. required
    Returns

    PrefixCacheBillResult Sent and fresh token counts, cached and uncached USD quantity bills, dimensionless cost ratios, and per-turn USD amounts as floats.
    Notes

    Equation: sent = H*s0 + delta*H*(H-1)/2; fresh = s0 + (H-1)*delta. Cached input costs p_in*(fresh + cached_fraction*(sent-fresh)).

    RetryPolicyModel

    engine.solvers.cost_accounting.RetryPolicyModel()

    Bounded attempt policies under independent attempts at a fixed all-in cost.

    Sequential retry with early stopping covers 1 - (1 - p)^k of tasks in coverage / p attempts on average, so its cost per accepted task is c / p whatever the cap; a batch of k pays for all k.

    strong_attempt_cost Quantity Comparison configuration charge, convertible to USD. required

    WorkloadLeverModel

    engine.solvers.cost_accounting.WorkloadLeverModel()

    Cost per accepted task by workload, C_eff = C_attempt / p_acc, and three levers.

    Halving the token price saves half the model share; halving the largest term saves half its share; raising acceptance by dp saves dp / (p + dp) of every term, and also removes the handoffs charged per rejected attempt. Acceptance beats halving tokens whenever the model share is below 2 dp / (p + dp).
