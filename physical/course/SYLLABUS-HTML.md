# Optional Quarto HTML skin (not required)

The **canonical student syllabus** is [`README.md`](README.md). GitHub renders it; that is enough.

`Physical-AI-Systems.qmd` / `./render-syllabus.sh` only exist if you want a local HTML copy. Prefer editing `README.md` and linking to it.

If you do render HTML and it looks too narrow, widen or delete the `max-width` rule in `syllabus.css`—that constraint was intentional for “article” layout and is easy to overdo on wide monitors.
