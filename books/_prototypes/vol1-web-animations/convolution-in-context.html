Convolutional layers

Convolutional layers typically use small spatial kernels (3×3 or 5×5) to maintain compact parameter footprints while stacking layers to widen the effective receptive field. Each output activation depends on one small window of the input.

In the figure below, a 3×3 receptive field in a 7×7 input produces one value of the 5×5 output map, and sliding the same filter to every position fills in the rest.

Each output value uses a local window, but every position uses the same nine weights. The filter therefore produces 25 output values without requiring a different set of parameters at each location.
