DIAGRAMS THAT COME TO LIFE — DESIGN PASS
October 18, 2026

A design pass on all 16 enrolled lessons across Volumes I–IV, not a rollout to every image.
This catalog implements no player changes. Quantization is the separate first prototype being developed alongside this review; all storyboards here remain proposals until implemented and verified.

Evidence: Design/source review only. No actual student feedback, user study, preference ranking, or measured learning gain is asserted.
Review basis: Rendered the 16 current canonical source assets from the existing HTML build and inspected contact sheets. Read local source/context and runtime JS/CSS. Did not rerender all interactive states or rebuild print targets for this design pass.

SOFTWARE
Semantic HTML controls + inline SVG scene + scoped CSS + small browser JavaScript controller.
Native Web Animations API or CSS transitions for interpolation. Keep stable objects/paths with declared causal transitions and one deterministic state reducer. Interpolation never owns numerical state.
SVG retains crisp labels and inspectable spatial identity; native browser controls fit Quarto and avoid a separate application or export pipeline.
HTML animates; PDF/EPUB/print/no-JavaScript keep the canonical complete static asset. Reduced motion uses equivalent discrete states.

SELECTION: DEFAULT STATIC
Keep the other 691 figures static. No inactive tabs or player controls, no coverage quotas, and no revival of withdrawn guided tours.
1. Name one transformation, spatial computation, causal handoff, allocation/release boundary, or ownership change that students can observe more clearly than in the complete static figure.
2. Preserve the original objects, orientation, arrows, geometry, color meanings, units, and local assumptions. A numeric toy is explicitly supplementary.
3. Make before→transition→after visible in the same diagram. A moving border, glow, traveling unlabeled dot, or prose slideshow does not qualify.
4. Keep persistent state visible through the sequence; show copies versus moves and retained versus released resources when relevant.
5. Use only a short current-action sentence by default. Detailed arithmetic/ledger/schema appears on selecting the relevant object.
6. Verify the actual themed chapter, desktop/narrow, light/dark, pause/manual jumps, reduced motion, and static fallback before calling it integrated.
Normally static: D·A·M intersection landscape and other taxonomies; chapter maps and conceptual relationship overviews; static architecture inventories without a specific runtime mechanism; historical/observational plots without a justified inspection interaction.
Tensor layout can remain an interactive lookup without continuous animation. Stopping-budget may revert to static if cumulative comparison adds no learner value. Stateful does not automatically mean animation-worthy.
