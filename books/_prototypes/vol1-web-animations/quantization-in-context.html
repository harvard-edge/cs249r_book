Rounding and clipping

Quantization maps a range of real values onto a finite set of integer codes. The scale sets the distance between reconstructed values; the zero point determines which code represents real zero.

The figure follows one value through scaling, rounding, and reconstruction, then repeats the process for a value outside the representable range.

A smaller scale gives more closely spaced reconstructed values for a fixed code count, but also narrows the supported range. Calibration must balance rounding error against clipping; the effect on model quality still requires evaluation.
