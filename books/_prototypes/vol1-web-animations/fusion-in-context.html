Kernel fusion

The cost of a memory-bound operation depends on where its operands live. Separate kernels commonly exchange intermediate tensors through high-bandwidth memory (HBM), even when the next operation immediately consumes them.

Kernel fusion combines compatible operations into one kernel. The following two-operation example follows the intermediate value to show which memory trips can disappear.

Fusion can keep an intermediate tile in registers or SRAM until its next consumer uses it. The benefit depends on local storage, compiler support, and the workload; this diagram counts idealized HBM transfers, not elapsed time.
