    Prefill and decode exhibit fundamentally divergent unit cost equations:
    }
    \vspace{1pt}
    \begin{equation*}
      {\textstyle c_{\text{prefill}} = \frac{C_{\text{node}} \cdot 2P}{3600 \cdot \eta \cdot \text{FLOPS}}}, \quad
      {\textstyle c_{\text{decode}}(B) = \frac{C_{\text{node}} \cdot P \cdot b}{3600 \cdot B \cdot \beta_{\text{HBM}}}}
    \end{equation*}
    {\fontsize{5.8}{7}\selectfont
    \textbullet\ \textbf{FLOP vs. Bandwidth Asymmetry:} Prefill saturates Tensor Cores ($I \gg 100$), amortizing memory access across large prompt batches.\\
    \textbullet\ \textbf{Decode Tariff Penalty:} Autoregressive decode collapses to $I \approx 1\text{ FLOP/byte}$, making output generation $3\times\text{--}5\times$ more expensive than prefill at low agent concurrency $B \ll B^*$.
    }

% Card 2: The Tax on Unreliability
\node[anchor=north west, fill=coolparchment, draw=RedLine!70, line width=0.9pt, rounded corners=4pt, inner sep=4pt] 
  (rcard2) at (9.4, 4.5) {
  \begin{minipage}{8.8cm}
    {\fontsize{7.5}{9}\selectfont \textbf{\textcolor{deepburgundy}{2. The Hyperbolic Tax on Unreliability ($\tau_{\text{unrel}}$)}}}\\[2pt]
    {\fontsize{6.2}{7.6}\selectfont
    The dimensionless multiplier counting failed attempts per accepted task:
    }
    \vspace{1pt}
    \begin{equation*}
      \tau_{\text{unrel}}(\alpha) = \frac{1 - \alpha}{\alpha} \implies \lim_{\alpha \to 0} \tau_{\text{unrel}}(\alpha) = \infty
    \end{equation*}
    {\fontsize{5.8}{7}\selectfont
    \textbullet\ \textbf{Non-Linear Inflation:} Near $\alpha \to 1.0$, the tax is negligible ($\tau(0.90) = 0.11$). Below the critical threshold $\alpha = 0.50$, the tax exceeds unity ($\tau(0.25) = 3.00, \tau(0.10) = 9.00$).\\
    \textbullet\ \textbf{Financial Destruction:} When reliability falls, discarded sandbox lifecycles, redundant tool RPCs, and re-sent prefix tokens wipe out all nominal savings.
    }
  \end{minipage}
};

% Card 3: Bayes Routing Threshold

    {\fontsize{7.5}{9}\selectfont \textbf{\textcolor{forestsage}{3. Bayes-Optimal Model Routing Threshold ($\tau^*$)}}}\\[2pt]
    {\fontsize{6.2}{7.6}\selectfont
    Optimal dispatch boundary between small and frontier models:
    }
    \vspace{1pt}
    \begin{equation*}
      \tau^* = \frac{C_{\text{frontier}} - C_{\text{small}}}{V_{\text{task\_success}} \cdot \Delta P(\text{success})}
    \end{equation*}
    {\fontsize{5.8}{7}\selectfont
    \textbullet\ \textbf{Economic Invariant:} Route to the frontier model if and only if predicted marginal accuracy gain $\Delta P > \frac{C_{\text{frontier}} - C_{\text{small}}}{V_{\text{task\_success}}}$.\\
    \textbullet\ \textbf{Asymmetric Loss:} Routing down wrongly wastes a full execution cycle; routing up wrongly wastes only the tier tariff difference.
    }
  \end{minipage}
