\frontside
\begin{bigidea}
A schema-valid tool call still starts code that reaches whatever its environment allows. The limit
must be \hl{enforced beneath the process}, not requested of the model; confinement costs
\hl{startup, memory and reset} per trajectory.
\end{bigidea}

\begin{leftcol}
\sheetsec{Key ideas}
\begin{ideas}
\idea{Admission is not containment.}{A well-typed call can still read credentials or open a socket.}
\idea{Pruned names keep their authority.}{Code in the supervisor's interpreter reaches its objects by
  reference; native libraries share its memory.}
\idea{Capability, not identity.}{Default reach is empty: code holds only references its grant
  handed it. A broker holds credentials outside the guest and acts only as granted.}
\idea{An envelope is where a system call lands.}{Choose by code, authority and holding time; audit mounts, devices and routes, not the label.}
\idea{Egress is enforced outside the guest.}{A packet filter passes only the mediator, which resolves
  exact hostnames; allowed calls and lookups still carry data.}
\idea{Reuse only after a verified reset.}{Clear four domains: execution and memory, storage,
  network and broker authority, host devices. A file scan cannot certify it.}
\end{ideas}

\vspace{8pt}
\fcard{Capability admission and attenuation}%
  {\begin{gathered}\text{admit} \iff \text{authentic}(\CapabilityGrant) \land \ProposedAccess.\text{op}\in\GrantRights
   \land \ProposedAccess.\text{target}\sqsubseteq\CapabilityObjectScope\\
   \land\ \GrantCondition(\ProposedAccess) \land \AccessAttemptTime < \GrantExpiryTime,
   \qquad \ChildCapabilityGrant \sqsubseteq \ParentCapabilityGrant\end{gathered}}%
  {Grant $\CapabilityGrant$: rights, objects, condition $\GrantCondition$, expiry. A child may only drop
   rights, narrow objects, add conditions or expire earlier.}%
  {Deriving a child leaves the parent usable; expiry blocks new opens, not live handles. Withdraw the
   parent and close handles.}{}

\fcard{Setup: per call or per trajectory}%
  {\begin{gathered}\text{fresh} = \EnvelopeCallCount(\EnvelopeSetupTime+\CallUsefulWorkTime), \qquad
   \text{kept} = \EnvelopeSetupTime+\EnvelopeCallCount\,\CallUsefulWorkTime\\
   \CallUsefulWorkTime \ge \EnvelopeSetupTime(1-\SetupShareCap)/\SetupShareCap\end{gathered}}%
  {$\EnvelopeCallCount$ calls of work $\CallUsefulWorkTime$. Setup is $\EnvelopeSetupTime/(\EnvelopeSetupTime+\CallUsefulWorkTime)$
   of a fresh call; the bound caps it at $\SetupShareCap$.}%
  {Kept state carries over: within one task only.}{}
\end{leftcol}%
\begin{rightcol}
\sheetsec{Four envelopes}
\begin{sheettable}{@{}l L l L@{}}
\thead{Envelope} & \thead{A system call lands} & \thead{Start} & \thead{Fits}\\ \midrule
Container & host kernel, after a filter & ms & reviewed code, no secrets\\
User-space kernel & emulator: trap, emulate, switch & ms & untrusted, few calls\\
MicroVM & own guest kernel; device I/O exits & ms (snapshot) & untrusted native code\\
Bytecode & nowhere: host imports only & \textmu s--ms & parsers, per-call tools\\
\end{sheettable}
\vspace{4pt}\noindent Per system call, an envelope pays some of trap, filter and switch: call-heavy
builds favor a guest kernel over an emulator. A one-byte first write copies a whole file (file-level
overlay) or one block (block-level).\par

\sheetsec{Worked example}
\begin{practicebox}\boxtitle{How large a pool for steady repair traffic?}
Trajectories arrive at \val{lam}/s, each holding a sandbox \val{hold}~s. Restore \val{restore}~ms;
miss target \val{target}\%. Template \val{guestmib}~MiB (\val{guestgb}~GB); \val{dirty}~MB written
per lease, \val{standby}~MB per standby.\par\vspace{2pt}
\begin{steps}
\item Active leases: \val{lam} $\times$ \val{hold} = \res{\val{active}}.
\item Arrivals per restore: \val{lam} $\times$ \val{restoresec}~s = \val{mu}. One standby misses with
  $1-e^{-\val{mu}}$ = \val{pone}\%, above target; two, $1-e^{-\val{mu}}(1+\val{mu})$ = \val{ptwo}\%.
  Reserve \res{\val{reserve}}.
\item Memory: \val{guestgb}~GB + \val{active} $\times$ \val{dirty}~MB + \val{reserve} $\times$ \val{standby} MB
  = \res{\val{poolgb}~GB}.
\item Private images: \val{active} $\times$ \val{guestmib}~MiB = \val{privatemib}~MiB = \res{\val{privategb}~GB},
  \val{memratio}$\times$ as much.
\end{steps}\vspace{3pt}

\begin{rightcol}
\sheetsec{Common mistakes}
\mistake{``With empty \texttt{\_\_builtins\_\_} and one helper, the script reaches nothing else.''}%
  {The helper's \texttt{\_\_globals\_\_} hands back the supervisor's namespace; a subclass walk
   reaches every loaded class. A process or VM boundary bounds reach.}{}
\mistake{``Copy-on-write is cheap, so a one-byte edit copies one byte.''}%
  {A file-level overlay copies the whole file on first write: one byte in a \val{fixture}~GB fixture
   across \val{ws} workspaces copies \val{filecopy}~GB, against \val{blockcopy}~KB in \val{block}~KB blocks.}{}
