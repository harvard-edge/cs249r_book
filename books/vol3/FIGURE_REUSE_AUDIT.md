# Volume III: Figure Reuse Audit

**Status:** Editorial and visual audit for the proposed chapter and section plan. No source image has been changed or deleted. “Retire” means remove from the proposed teaching narrative; it does not authorize deleting the source asset.

## Scope and evidence

The volume contains 233 image files: 127 SVGs, 70 PNGs, and 36 WebPs. The Quarto image references resolve to 145 existing files: 108 body SVGs in the eighteen teaching chapters, 36 print/web chapter-cover variants, and one reference-architecture appendix SVG. The remaining 88 files include unlabeled cover masters, generated raster copies, duplicate diagrams, and unused candidates. No missing image-reference targets were found by the inventory scan.

The chapter reviews inspected rendered body SVGs and the referenced print/web cover files. Rendering and inspection distinguish visible layout defects from questionable technical claims in embedded labels. This audit establishes reuse decisions, not print-production approval. Revisions must be rendered and inspected again at their intended publication size.

A figure can have reusable composition and incorrect text at the same time. A visually polished curve can still require complete replotting if its data, axes, or claimed law are unsupported. The dispositions below separate these cases.

## Disposition rules

| Disposition | Meaning for revision |
|---|---|
| Reuse | Preserve the visual mechanism and layout; review caption, alt text, labels, and target context before insertion. |
| Revise | Keep useful geometry or artwork and correct, simplify, or replace embedded content. |
| Move | Place the asset at the concept's teaching home; apply any stated revisions and avoid retaining an unexplained duplicate. |
| Supporting material | Preserve a useful implementation example outside the main chapter arc. |
| Retire from narrative | The asset's teaching claim no longer earns a place; preserve the original file until a separate cleanup decision. |
| New or replot | The required argument is missing or the existing visual encodes a misleading quantitative result. Build from a reviewed brief or sourced data. |

## Reuse priorities

1. Preserve clear flow diagrams, state transitions, memory layouts, and comparative compositions when their mechanisms remain relevant.
2. Reuse cover artwork through existing unlabeled masters where possible. Update labels and truthful alt text independently of the artwork.
3. Consolidate duplicated diagrams under one conceptual owner. Resolve exact copies and generated derivatives before editing to prevent contradictory versions.
4. Correct the labels that make literal computer correspondences or universal guarantees. A changed caption cannot repair an incorrect assertion drawn inside the image.
5. Use new diagrams only where the learning argument requires information absent from existing compositions. Use computed plots for numerical relationships.

## Memory and storage
### How to read the decisions

- **Revise:** Retain the existing asset/layout or illustrated base, but change its claims, labels, or composition before reuse. It is not approved unchanged.
- **Move:** Preserve the asset for a different teaching location, with any stated revisions first.
- **Retire from body:** Keep the file for reference or optional supporting material; do not include it in the main narrative solely because it already exists.
- **Visual evidence** below comes from actual raster inspection. **Source evidence** comes from the chapter reference/caption or the conceptual claim being taught. A clear-looking diagram can still teach the wrong relationship.

## Tools and I/O
### Inspection method and limits

Inspected all 11 locally embedded body SVGs and all 4 referenced cover renditions. SVGs were actually rasterized with rsvg-convert at 1400–1500 pixels wide and displayed; raster covers were opened with view_image. Rendered bytes were streamed without creating image files. No manuscript or image assets were changed.

The audit checks visual content, conceptual fit, density, and visible layout. It is not a full chapter-PDF layout proof or a completed citation audit. All listed asset decisions are based on inspected images, not filenames alone.

Uninspected: unused alternate image exports; the shared LaTeX margin stack; figures only cross-referenced from another chapter, such as fig-vol3-context-state-vs-effectful-io. Their owning chapter agents should handle them. No locally embedded body figure or referenced cover rendition in Chapters 7–8 remains uninspected.
