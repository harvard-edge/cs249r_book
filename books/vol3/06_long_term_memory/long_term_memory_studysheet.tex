\begin{bigidea}
Records that outlive a session are durable state later sessions act on. Each is a \hl{claim}
carrying its source, the versions it holds for and a path to invalidation; the \hl{runtime}, not the
model, decides what is admitted, returned and retired.
\end{bigidea}

\begin{leftcol}
\sheetsec{Key ideas}
\begin{ideas}
\idea{Records have roles.}{Source of record, observation log, agent-written memory, derived index.
  Check claims at the source of record; an index only locates.}
\idea{Every read has a contract.}{Bounds in, envelope out: snapshot, status, provenance. Empty
  proves absence only after a complete, exhaustive search.}
\idea{Admit, then deduplicate.}{Check owner, scope, kind and evidence first: similarity mistakes
  revisions for repeats. Same scope supersedes; a narrower scope coexists.}
\idea{Repetition is not evidence.}{Reuse adds no support. Withdrawal cascades to every derived copy:
  tombstone now, purge later; backups and sent calls lie outside.}
\idea{Valid by generation.}{Entry $\DerivedMemoryEntry$ answers a query at generation $\QueryWorkspaceGeneration$
  only if $\MemoryEntryBirthGeneration(\DerivedMemoryEntry) \le \QueryWorkspaceGeneration < \MemoryEntryDeathGeneration(\DerivedMemoryEntry)$;
  death stays open ($\infty$) until an edit changes its source.}
\idea{Exclude now, rebuild later.}{Exclusion is metadata at the source commit; rebuilding is
  encoder work. Meanwhile serve a direct read or explicit partial result.}
\end{ideas}

\sheetsec{Common mistakes}
\mistake{``The 11:00 rule is a near-duplicate of the 10:00 rule; keep one.''}%
  {Similarity puts a revision beside the record it replaces. Match owner, scope and kind first: on one
   calendar, 11:00 supersedes (10:00 stays in history); ``Fridays only'' is narrower, so both stand.}{}
\mistake{``Fill the allowance by counting record bodies.''}%
  {A body count admits \val{bodyonly} records of \val{body} tokens; with \val{meta} metadata each and a
   \val{envelope}-token envelope they take \val{bodyonlyused}, \val{overshoot} over the allowance. Only \val{records} fit.}{}
