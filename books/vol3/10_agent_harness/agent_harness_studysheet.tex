\frontside
\begin{bigidea}
A model asked to pause, wait or stay in budget honors it on almost every turn; over a long
\hl{horizon} that still fails. So the \hl{harness} decides each next step: it owns the trajectory's
record, \hl{admits} every model call and tool dispatch, and keeps an owner for every effect in flight.
\end{bigidea}

\begin{leftcol}
\sheetsec{Key ideas}
\begin{ideas}
\idea{Continuation lives outside the model.}{A rule kept independently on \val{follow}\% of turns holds
  over all \val{ruleturns} turns in only \val{hold}\% of runs. Every reply is an untrusted proposal.}
\idea{One record, one writer.}{The trajectory record (state, grants, reservations, operation table,
  live plan) is written only by the harness; model text never moves a meter.}
\idea{Guarded transitions; register before send.}{A legal edge is not enough: under the record
  lock the check reserves and registers before the request leaves.}
\idea{Eligibility is not settlement.}{A timeout or interrupt advances the epoch, so a late result skips
  the current turn; its charge and owner stay until evidence settles them.}
\idea{Control lands at turn boundaries.}{Before each model call and tool dispatch. Streaming
  cancellation stops generation; canceled or truncated output never dispatches.}
\idea{Waits release threads, not resources.}{Lease, cache, reservations and deadline stay. Escrow holds
  the exact proposal; approval is a precondition, not an order.}
\end{ideas}

Any live state can stop into FINALIZING (cancel, kill, budget). A mid-wait pause withdraws the wait
and any held approval (late decisions become audit only), then steps through READY to PAUSED. Resume
reruns admission; evidence covers only the revision it tested.\par

\begin{rightcol}
\fcard{Bounded-liability admission}%
  {\begin{gathered}\text{actual} + \text{reserved} + \text{liability} + \text{final reserve} \le \text{allowance}\\[2pt]
   \text{liability} = \InputTokenPrice\,\SequenceLength + \OutputTokenPrice\,\OutputLimit\end{gathered}}%
  {Checked for turns, tokens, time and dollars. A call reserves $\SequenceLength$ input tokens at full price
   $\InputTokenPrice$, cached or not, and its whole output allowance $\OutputLimit$ at $\OutputTokenPrice$; usage settles it.}%
  {Ceiling: lowest $\CostPerAcceptedTask = \mathbb{E}[\AttemptCost]/\AcceptanceProbability$ with liabilities
   in bounds; halts count as unaccepted.}{}
\fcard{Turn-boundary delay}%
  {\TurnBoundaryDelay \approx \OutputLimit \times \PerTokenDecodeTime}%
  {Checked only when a reply ends, a pause waits out the call:
   \val{kmax} tokens at \val{tdec} ms $\approx$ \val{twait} s.}%
  {Linear in $\OutputLimit$; streaming cancellation removes it.}{}
\fcard{Held approvals (Little's law)}%
  {\ApprovalHeldTrajectories = \ArrivalRate\,\ExternalWait}%
  {Requests at $\ArrivalRate$ waiting $\ExternalWait$ on average. Repair: \val{lam}/h $\times$ \val{waith} h =
   \val{held} held, each keeping a \val{lease} MiB lease: \val{retgib} GiB (\val{retgb} GB).}%
  {Mean, not peak: size for bursts.}{}
\fcard{Weighted deficit round-robin}%
  {\text{calls per round} = \frac{\SchedulingClassWeight \times \text{quantum}}{\SequenceLength + \OutputLimit}}%
  {A class\textquoteright s charge share is $\SchedulingClassWeight$ over the summed weights; a call costs input plus output
   allowance. Weights \val{wint}:\val{wmnt}, calls of \val{chgint} vs.\ \val{chgmnt}: interactive gets
   \val{shareint}\% of the charge, \val{callratio}$\times$ the calls.}%
  {Credit cap $\ge$ largest charge. Quotas and budgets are separate gates.}{}
\end{rightcol}

\begin{steps}
\item Liability: \val{inputtokens} $\times$ \$\val{pin}/M + \val{kout} $\times$ \$\val{pout}/M = \val{cin} + \val{cout}
  = \res{\$\val{liab}}.
\item Spend check: \val{allow} $-$ \val{settled} = \res{\$\val{spendhead}}: admits.
\item Reservation test: \val{spendhead} $-$ \val{reserved} $-$ \val{fin} = \res{\$\val{head}} $<$ \$\val{liab}: refuses;
  admitted, final checks would be \$\val{short} short.
\item Fit: input $\le$ (\val{head} $-$ \val{cout}) $\div$ \$\val{pin}/M $\approx$ \res{\val{nmax} tokens}.
\end{steps}
\takeaway{Admission counts what is owed, not just billed.}

\sheetsec{Common mistakes}
\mistake{``Our loop is async, so a pause takes effect at once.''}%
  {Coroutines free threads, not control. Checking only when a reply ends, a pause waits \val{twait} s behind
   a \val{kmax}-token allowance; record the pause and cancel the stream.}{}
\mistake{``The test timed out, so its reservation is free again.''}%
  {A timeout ends the wait, not the job. Releasing \$\val{reserved} hands \val{resshare}\% of the allowance
   to later calls, which overshoot by up to that much when the bill arrives.}{}
\mistake{``A tighter ceiling is cheaper: each run costs less.''}%
  {Halted runs cost and count as unaccepted. \assumed{} \$\val{ceilacost} per attempt at \val{ceilaacc}\%
   accepted gives \$\val{ceilacost} $\div$ \val{ceilaaccfrac} = \$\val{ceilaeff} per accepted repair; a looser
   ceiling at \$\val{ceilbcost} and \val{ceilbacc}\% gives \$\val{ceilbeff}.}{}
