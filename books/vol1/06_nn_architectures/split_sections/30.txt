### Computational mapping {#sec-network-architectures-computational-mapping-aea3}

Expanding sequence length $S$ challenges accelerator memory hierarchies because full-sequence self-attention scales quadratically with context length. @Fig-context-explosion charts this scaling trajectory on a logarithmic axis, showing context windows growing from 2K tokens to beyond 128K and into the 1M-token range [@openai2023devday; @anthropic2023claude21; @google2024gemini15]. These product milestones matter less than the principle they illustrate. Longer context windows shift complexity from external retrieval and document chunking pipelines into accelerator memory capacity and bandwidth budgets. Exact tiling changes how much attention state is stored while retaining dense quadratic arithmetic; sparse attention instead reduces the interactions computed (@sec-network-architectures-memory-requirements-72c3).

@Lst-self_attention_layer presents a typical implementation, showing how self-attention derives queries, keys, and values from the same input sequence.

::: {#lst-self_attention_layer lst-cap="**Self-Attention and Multi-Head Attention**: Self-attention (top) derives $\mathbf{Q}$, $\mathbf{K}$, and $\mathbf{V}$ from the same input $\mathbf{X}$ through three projections, then computes attention as before. Multi-head attention (bottom) runs $\NumberOfAttentionHeads$ parallel attention heads with dimension $\AttentionHeadDimension = d/\NumberOfAttentionHeads$, then concatenates and projects. For GPT-2 (768-dim, 12 heads), each head operates on 64 dimensions, partitioning the projected feature dimension across heads while enabling diverse relationship patterns."}

```{.python}
def self_attention_layer(X, W_Q, W_K, W_V, d_head):
    # X: input tensor (batch_size × seq_len × d_model)
    # W_Q, W_K, W_V: weight matrices (d_model × d_head)

    Q = matmul(X, W_Q)
    K = matmul(X, W_K)
    V = matmul(X, W_V)

    scores = matmul(Q, K.transpose(-2, -1)) / sqrt(d_head)
    attention_weights = softmax(scores, dim=-1)
    output = matmul(attention_weights, V)

    return output

def multi_head_attention(X, W_Q, W_K, W_V, W_O, num_heads, d_head):
    outputs = []
    for i in range(num_heads):
        head_output = self_attention_layer(
            X, W_Q[i], W_K[i], W_V[i], d_head
        )
        outputs.append(head_output)

    concat_output = torch.cat(outputs, dim=-1)
    final_output = matmul(concat_output, W_O)

    return final_output
```

Parallel sequence processing shifts fundamentally during autoregressive inference: generating output tokens step-by-step reintroduces sequential serialization and converts compute-bound matrix multiplications into memory-bandwidth-bound matrix-vector operations, as quantified in @sec-network-architectures-system-implications-77ac via the GPT-2 XL lighthouse.
