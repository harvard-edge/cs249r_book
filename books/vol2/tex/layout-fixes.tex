%
% Same fix as vol3/tex/layout-fixes.tex (cc4856c83a). longtable starts with
% \global\@colroom\@colht and never restores it. When a top float already sits
% on the current page, LaTeX then believes the page has a full column free,
% admits a second float, and the page overflows. CI pdf-verify caught this as
% overfull \vbox plus page-edge-overflow (Vol I pp. 399 and 867, Vol II p. 729,
% dev run 45003305139). Resynchronizing after the environment is correct
% whether or not the table broke across pages.
\makeatletter
\AfterEndEnvironment{longtable}{\global\@colroom\vsize}
\makeatother
