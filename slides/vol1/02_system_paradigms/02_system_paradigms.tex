\mlsysnote{[0.5 min] [CORE] The second wall lives inside every machine, in moving bytes from memory to the arithmetic units.}
\mlsysdivider{Why do fast processors sit idle waiting for bytes?}{System Paradigms, \S2.2, \S2.3, and \S2.4}
\section{Memory}

\begin{frame}{Compute has outgrown memory bandwidth for decades}
  \centering
  \safeimg[width=0.95\textwidth,height=5.3cm,keepaspectratio]{memory_wall_measured.pdf}\\[0.05cm]
  {\normalsize Over twenty years: peak FLOP/s about \val{wall_flops_20y}$\times$, DRAM bandwidth about \val{wall_dram_20y}$\times$.}
  \mlsyscredit{Data: Gholami et al., ``AI and Memory Wall,'' IEEE Micro 2024, Fig.\ 1 (server chips, normalized to each series' first point), redrawn; Wulf and McKee 1995.}
  \note{[2 min] Every point is a real chip. Each dot is a published server processor, GPU, or TPU (orange), a DRAM generation (blue: GDDR3 through HBM2E), or an interconnect generation (violet: PCIe and NVLink), each series normalized to its own first point. The lines are least-squares fits on the logarithm, as in the paper. Peak compute grew about \val{wall_flops_2y} times every two years, about \val{wall_flops_20y} times over twenty years; DRAM bandwidth \val{wall_dram_2y} times every two years, about \val{wall_dram_20y} times; interconnect \val{wall_ic_2y} times, about \val{wall_ic_20y} times. The gap between orange and blue is the memory wall, which Wulf and McKee named in 1995.
