    \mlsysnotemeta{1.5 min}{Core}%

On June 4, 1996, the European Space Agency (ESA) launched Flight 501 of its new Ariane 5 rocket, whose guidance software was reused from its predecessor, Ariane 4. That reused code converted a 64-bit floating-point number into a signed 16-bit integer, whose maximum value is 32,767.     \notecue{Watch for}{This failure is often mistaken for a logic error. The logic was valid for Ariane 4, yet live numbers escaped the format's representable range.}

\begin{frame}{Learned features cost 1,100 times the work of rules}
  \centering
  \mlsyssteps[width=0.95\textwidth,height=4.9cm,keepaspectratio]{ops_ladder_step}{3}
  \mlsyscredit{Neural Computation, \S5.2; illustrative implementations of each method for one $28{\times}28$ digit.}
  \note{%
    \mlsysnotemeta{2.5 min}{Core}%
    Holding the same digit fixed across three eras shows what learned features actually cost the machine. First, hand-written pixel rules need roughly 100 comparisons, yet they break easily whenever handwriting varies. Next, engineered edge descriptors using Histogram of Oriented Gradients (HOG, recalled from Lecture 1) paired with a linear classifier (a model that scores each class with a weighted sum of features) take roughly 8,000 operations and 2 KB of state, fitting easily on a CPU. Finally, the learned multilayer perceptron (MLP) runs 109,184 MACs, which is $1{,}100\times$ the work of rules, and stores 438 KB of weights, already exceeding a CPU's level-1 (L1) cache, the smallest and fastest on-chip memory. That trade of human design for arithmetic embodies Lecture 1's Bitter Lesson at the single-network scale.

    \notecue{Watch for}{These counts come from illustrative implementations rather than universal constants. What matters is the order-of-magnitude leap and the shift from branching to memory traffic and parallel math.}

\begin{frame}{After 2010, parameter counts doubled every 10 months}

  \note{%
    \mlsysnotemeta{1.5 min}{Optional}%
    If learned arithmetic beats rules, why did neural networks wait decades to scale? Parameter counts across 725 published models in Epoch AI's Notable AI Models registry (recalled from Lecture 1) doubled roughly every 43 months before 2010, then every 10 months afterward, passing a trillion parameters far above MNIST. Paul Werbos applied backpropagation (computing weight gradients from output errors) to neural networks in 1974, and David Rumelhart, Geoffrey Hinton, and Ronald Williams showed in 1986 that hidden layers learn useful features. Practical scaling still waited for GPUs, large datasets, better weight initialization (setting starting weight scales), the rectified linear unit (ReLU) activation (defined in Segment 2), and software frameworks. Every jump in parameter count multiplies arithmetic and memory traffic, so pricing a network starts by counting its layers.

      \uncover<1->{$z_j = \sum_i x_i\, w_{ij} + b_j$}\\[0.35cm]
      \uncover<2->{$\hat{y}_j = f(z_j)$}\\[0.5cm]

      {\small\textcolor{midgray}{784 for a first-layer unit}}}
    \end{column}
  \end{columns}
  \note{%
    \mlsysnotemeta{1.5 min}{Core}%
    Start with the smallest building block of any network, recalling Rosenblatt's 1958 perceptron (Lecture 1). One neuron runs two steps. First, it forms a weighted sum of its inputs plus a bias (a learned offset), $z_j = \sum_i x_i w_{ij} + b_j$. Second, it applies a nonlinear activation function, $\hat{y}_j = f(z_j)$, most commonly the rectified linear unit (ReLU), which zeroes negative values and passes positive values unchanged. For $n$ inputs, that sum costs $n$ MACs, so one first-layer MNIST unit costs 784 MACs. Without reuse, each MAC fetches an input and a weight from memory, so memory traffic competes with arithmetic.

    \notecue{Check}{How many MACs do all 128 first-layer units perform together on one digit? Each of the 128 units multiplies all 784 inputs by its own weights, giving $784 \times 128 = 100{,}352$ MACs. A tempting error is to add 784 and 128, which overlooks that every input connects to every unit.}

    \notecue{Watch for}{The biological neuron is strictly a historical metaphor rather than a physical model of what the math computes.}

    \notecue{Next}{Examine why networks require nonlinear activations using the classic exclusive-OR (XOR) problem.}
  }
\end{frame}

\begin{frame}{Two ReLU units compute XOR; no single weighted sum can}
  \begin{columns}[c]
    \begin{column}{0.52\textwidth}
      \centering\normalsize
      \begin{tabular}{@{}cc|cc|c@{}}

      \uncover<3->{{\small\textcolor{midgray}{Without a nonlinearity, any network collapses to one linear map.}}}
    \end{column}

  \note{%
    \mlsysnotemeta{1.5 min}{Optional}%
    Why does a neuron need the nonlinear step $f(z_j)$ at all? In 1969, Minsky and Papert proved that no single-layer perceptron can compute XOR, a landmark result showing why multilayer nonlinear networks are structurally necessary. On the unit square, no single straight line separates the filled $(0,1)$ and $(1,0)$ points from the open $(0,0)$ and $(1,1)$ points. Adding two hidden ReLU units solves it with $h_1 = \text{ReLU}(x_1 + x_2)$ and $h_2 = \text{ReLU}(x_1 + x_2 - 1)$. Combining them as $y = h_1 - 2h_2$ cancels $(1,1)$ back to 0 and carves out the diagonal band between $x_1 + x_2 = 0.5$ and $1.5$.

    \notecue{Watch for}{Adding more linear layers does not add expressive power. Without a nonlinearity between them, multiplying linear matrices collapses any depth back into one single linear map.}

    \notecue{Teach}{For a 50-minute class, skip this slide and note orally that nonlinearities stop deep networks from collapsing to one matrix.}

  \note{%
    \mlsysnotemeta{3 min}{Optional}%
    Stacking nonlinear layers raises a training question, because each layer multiplies the backward gradient (the error signal guiding updates, derived in Segment 4) by its activation slope. Sigmoid, $\sigma(z)=1/(1+e^{-z})$, peaks at slope 0.25 at zero and flattens at large inputs, whereas ReLU keeps slope 1 for positive inputs.     \notecue{Check}{From activation slopes alone, at most $0.25^{20}=9.1\times10^{-13}$ survives. In the 2012 AlexNet paper (Krizhevsky, Sutskever, and Hinton, Lecture 1), a four-layer convolutional neural network (CNN, Lecture 6) on CIFAR-10 hit 25\% training error in roughly 6 epochs (dataset passes) with ReLU versus 36 with hyperbolic tangent (tanh, another saturating S-curve), $6\times$ faster.}

    \notecue{Watch for}{ReLU does not guarantee safe gradients. Weights still multiply in, and always-negative units become dead ReLUs passing zero gradient.}

\begin{frame}{A sigmoid needs an exponential; a ReLU needs a comparison}
  \centering
  \mlsyssteps[width=0.92\textwidth,height=3.6cm,keepaspectratio]{transistor_tax_step}{2}\\[0.3cm]
  \uncover<2->{\normalsize The ratio is illustrative; real designs use lookup tables or piecewise fits.}
  \mlsyscredit{Neural Computation, \S5.3.2: a stylized teaching ratio (illustrative), not a measured constant.}
  \note{%
    \mlsysnotemeta{1 min}{Optional}%
    Gradient flow is only half of ReLU's advantage, because activation choice also carries a silicon cost. Modeling ReLU as a sign-bit check (comparator) and a selector circuit (multiplexer) takes about 50 transistor equivalents, whereas the exponential needed by sigmoid or tanh takes near 2,500 transistor equivalents, an illustrative $50\times$ ``transistor tax.'' Beyond silicon area, which accelerators spend on multipliers instead (Lecture 11), separate (unfused) activations force costly memory round trips. Compilers therefore merge (fuse) activations directly into matrix multiplications (Lecture 7), and ReLU's backward pass needs only a 1-bit sign mask.

    \notecue{Watch for}{Treat the $50\times$ count as a stylized teaching budget rather than a fixed constant. Real chips approximate exponentials with precomputed tables (lookup tables) or simple curve segments (piecewise polynomials), still costing an order of magnitude or more.}

    \notecue{Teach}{For a 50-minute class, skip this slide freely.}

\mlsysnote{%
  \mlsysnotemeta{1.5 min}{Core}%
  Those exact MNIST numbers generalize into three rules for any dense layer with input width $n_{\text{in}}$, output width $n_{\text{out}}$, and batch size $B$. Parameters equal $(n_{\text{in}} + 1) n_{\text{out}}$, where the $+1$ adds one bias per output unit, and forward FLOPs equal $2 B n_{\text{in}} n_{\text{out}}$. Saved training activations scale as $B n_{\text{out}}$, because training must keep each layer's outputs for all $B$ examples in memory until Segment 4's backward pass consumes them. Layer widths thus fix parameters and MACs before any code runs. Between two adjacent hidden layers of equal width $W$, weights and FLOPs grow quadratically as $W \times W = W^2$, whereas stacking $L$ layers multiplies those counts only linearly with $L$. Keep these equations handy for Lectures 6 and 8.

\begin{frame}{Takeaways}
  \normalsize
  \begin{itemize}\setlength{\itemsep}{0.25cm}
    \item A dense layer costs one MAC per weight per example; widths fix it.
    \item Matrix multiply is over 99\% of the work; batching reuses each weight.
    \item Backpropagation reads saved forward values; a step is 2 to 3 forward passes.
    \item Training holds weights, gradients, optimizer state, and activations: 3.4$\times$ inference here.
    \item Without branches, a network's common failures are numerical range and memory.
  \end{itemize}
  \note{%
    \mlsysnotemeta{1 min}{Core}%
    Together, five principles answer what a neural network computes and what it costs the machine. Layer widths fix dense-layer MAC counts, and matrix multiplication dominates forward work while batching reuses each weight. Backpropagation reads saved forward values, so a full training step costs $2\times$ to $3\times$ the forward FLOPs. Training holds four kinds of state ($3.4\times$ inference here), and branch-free networks most commonly fail on numerical range or memory.
