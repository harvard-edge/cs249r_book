Step 3: the error sent back to the hidden layer is minus \val{bp_err_mag} times each output weight, minus \val{bp_back1_mag} and \val{bp_back2}, written beside each hidden unit. The ReLU mask zeroes unit 2's share, because its input was negative in the forward pass; that needed the saved z (or one saved bit). Step 4: each first-layer weight's gradient is its input times the hidden error, so \val{bp_x1} times minus \val{bp_back1_mag}, and \val{bp_x2} times minus \val{bp_back1_mag}, minus \val{bp_gw21_mag}; unit 2's weights get 0. The update, with learning rate \val{bp_lr}: w11 = \val{bp_w11} minus \val{bp_lr} times minus \val{bp_back1_mag} = \val{bp_w11_new}, nudging the output toward 1. ENGAGE: ask which forward value each step read. The backward pass cannot run without the forward values, so training keeps them in memory. WARN: backpropagation computes gradients; the optimizer applies the update. LINK: the next slide asks PyTorch what it kept.}
\end{frame}

\begin{frame}{Takeaways}
  \normalsize
  \begin{itemize}\setlength{\itemsep}{0.25cm}
    \item A dense layer costs one MAC per weight per example; widths fix it.
    \item Matrix multiply is over 99\% of the work; batching reuses each weight.
    \item Backpropagation reads saved forward values; a step is 2 to 3 forward passes.
    \item Training holds weights, gradients, optimizer state, and activations: \val{mem_ratio}$\times$ inference here.
