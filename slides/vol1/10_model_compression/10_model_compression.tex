\begin{frame}{Most of ResNet-50's weights can go for about one point}

  \mlsyssteps[width=0.95\textwidth,height=4.6cm,keepaspectratio]{prune_step}{3}\\[0.15cm]

  \note{%
    \mlsysnotemeta{2.5 min}{Core}%
    Formally, pruning minimizes loss subject to at most $k$ nonzero weights; because combinatorial search is intractable, magnitude serves as a cheap proxy (darker cells hold larger weights). First, start with a dense 6 by 6 weight matrix. Second, unstructured pruning zeroes the 18 smallest entries, yet the tensor keeps its shape so ordinary dense kernels still fetch and multiply every zero. Third, structured pruning deletes entire columns (output channels), leaving a smaller dense matrix that runs faster on standard phone CPU kernels without special support. Empirically, Gale, Elsen, and Hooker (2019) pruned roughly 80 percent of ResNet-50's weights by magnitude with retraining for about one point of top-1 accuracy.

    \notecue{Watch for}{Dropping weights on paper is not the same as running faster on silicon; the next four slides quantify the storage and runtime costs of sparsity.}

    Trace the chapter's 4 by 4 matrix-vector product. First, a dense kernel executes all 16 multiply-accumulates, zeroes included, reading 64 bytes of FP32 weights. \begin{frame}{Takeaways}
  \begin{itemize}\setlength{\itemsep}{0.28cm}\normalsize
    \item Find the limiting term first: arithmetic for the camera frame, weight bytes for a decode token, capacity for a microcontroller.
    \item Move a dominated model to the accuracy-efficiency frontier before trading along it.
    \item Remove structure the hardware can drop, or train a smaller dense student.
    \item Sparsity saves bytes and time only past a break-even set by the format and the kernel.
    \item Order the levers and measure after each; the rest of the pipeline caps the gain.
  \end{itemize}
  \note{%
    \mlsysnotemeta{1 min}{Core}%
    Read the five takeaways in order and invite students to identify which slide or measurement anchored each statement. If running short on time, emphasize the first (diagnose the limiting term) and last (measure after each ordered lever under Amdahl's cap).
