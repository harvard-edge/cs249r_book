\begin{frame}{A model is a function of four versioned inputs and the rounding}
  \centering
  \mlsyssteps[width=0.92\textwidth,height=5.3cm,keepaspectratio]{repro_step}{2}
  \mlsyscredit{ML Operations, equation 1 and footnote 4 (DVC), \S14.2.1.}
  \note{%
    \mlsysnotemeta{2.5 min}{Core}%
    Visualize Equation 1 across two steps. First, a model is a function of four pinned inputs: code (Git commit), data (content hash via tools like DVC, the input teams most often omit and cannot later recover), configuration/hyperparameters, and environment (container image with pinned libraries). Dropping any single pin breaks exact reconstruction. Second, even with all four pinned, parallel GPU floating-point additions are non-associative, so different reduction orders round differently and compound over thousands of steps; deterministic kernels enforce exact order at a speed penalty (reproducibility envelopes sit in Benchmarking \S12.8.2).
