\begin{frame}{ChatGPT's daily prompts use about half a GPT-3 run (estimate)}

  \mlsyssteps[width=0.95\textwidth,height=3.8cm,keepaspectratio]{fleet_daily_step}{2}\\[0.3cm]

  \note{%
    \mlsysnotemeta{2 min}{Core}%
    First, OpenAI reported roughly 2.5 billion ChatGPT prompts per day in July 2025; multiplying by Google's measured 0.24 Wh per prompt yields an estimated 600 MWh per day. \end{frame}

\begin{frame}{By the end of the course, you will be able to}
  \normalsize
  \begin{itemize}\setlength{\itemsep}{0.35cm}
    \item Estimate the time, memory, energy, and cost of a model.
    \item Diagnose whether data, algorithm, or machine limits a system.
    \item Decide where a model should run, from datacenter to microcontroller.
    \item Keep a deployed system fast, correct, and responsible.
  \end{itemize}
  \vspace{0.5cm}
  \threadstrip{1}{1}{1}{1}{1}
  \note{%
    \mlsysnotemeta{2 min}{Core}%

The bottom strip introduces two organizing threads that appear on every lecture's goals slide: the dual mandate (being right and fast enough together) and the iron law's three factors for data (D), algorithm (A), and machine (M).

    \notecue{Watch for}{Introduce the strip's labels here without deriving the iron law yet; Lecture 1 develops both threads quantitatively.}

    \notecue{Next}{Connect each of the four capabilities to a specific physical system and lecture.}
