\begin{frame}{The proposer's weight stream is the long burst ahead of the read}
  \centering
  \safeimg[width=0.80\textwidth,height=4.5cm,keepaspectratio]{socmem.pdf}\\[0.05cm]
  {\small $\text{wait} = \dfrac{\text{bytes queued ahead}}{\text{peak bandwidth}} + \text{row conflicts}\times(t_{\text{precharge}}+t_{\text{activate}})$}\\[0.05cm]
  {\footnotesize\textcolor{midgray}{One backlog (weight tile, camera, telemetry): 360,448\,B at 204\,GB/s + 3 $\times$ 37.5\,ns = \textbf{1.879\,µs}}}
  \mlsyscredit{Workload Placement, \S13.3.1, equation 1 and Napkin Math 13.1 (LPDDR5 at 6,400 MT/s; backlog illustrative).}
  \note{
  \mlsysnotemeta{2 min}{Core}%
  Connect Lecture 3's memory-wall weight streaming to unified SoC memory. Here the CPU cluster, proposer NPU, and real-time cores all reach one LPDDR5 controller through a shared fabric and last-level cache, placing the safety tick's 4~KB sensor read behind long weight bursts. Each request traverses issue, interconnect arbitration, controller queueing, and DRAM banks; switching an open DRAM row incurs precharge plus activate (18~ns each, rounded to 15 cycles of the 1.25~ns command clock, or 37.5~ns per conflict). \begin{frame}{Measured: partitioned victims still slow down up to 346$\times$}

\mlsysdivider{What measurement could prove the placement wrong?}{Workload Placement, \S13.7 and \S13.8}
\section{Refutation}

\mlsysnote{
  \mlsysnotemeta{1.5 min}{Core}%
  Read the lecture's central falsification rule: $\Tload = \Tiso + \Dint$, where $\Tiso \le \Twcet < \Tdead$. Because isolated execution cannot exceed the declared WCET and an independent placement claims $\Dint = 0$, any loaded tick exceeding $\Twcet$ (for instance, 260~$\mu$s, still 140~$\mu$s inside the 400~$\mu$s deadline) refutes the placement outright, because every downstream stopping margin assumed $\Dint = 0$. Passing below 250~$\mu$s never proves $\Dint = 0$ universally; it supports the claim only over tested states.

  \notecue{Watch for}{One slipped tick adds only 1.3~mm at 1.3~m/s, tempting teams to dismiss it; once the isolation premise breaks, nothing bounds the next stall.}

  \notecue{Next}{Students apply this falsification rule to a 300~$\mu$s loaded cycle on a shared-die candidate.}
}
