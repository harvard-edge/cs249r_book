\begin{frame}{Signed robustness turns testing into a search for the worst case}
  \begin{columns}[c]
    \begin{column}{0.54\textwidth}

      \small
      $\rho\,(\text{always } \varphi) = \min_t \rho(\varphi, t)$\\[0.05cm]
      {\footnotesize $\rho$: signed margin of a trace against a temporal requirement $\varphi$}\\[0.2cm]
      \uncover<2->{Falsification: choose the start state and disturbance that \textbf{minimize} $\rho$, within what a test bench can deliver.\\[0.15cm]}
      \uncover<3->{\footnotesize Tools: S-TaLiRo, Breach, VerifAI (Dreossi et al.\ 2019). An empty search certifies nothing.}
    \end{column}
  \end{columns}

  \note{
  \mlsysnotemeta{2.5 min}{Core}%
  Binary PASS/FAIL verdicts give an optimizer no gradient toward failure. Signal temporal logic (Maler and Nickovic, 2004; Fainekos and Pappas, 2009) assigns every continuous trace a signed robustness margin $\rho$: for ``always keep clearance,'' $\rho$ is the minimum clearance over time. First, Step 1 shows a passing trace staying at $+0.15\text{ m}$ clearance. Second, Step 2 shows a violating trace dipping $-0.04\text{ m}$ below the limit. Falsification minimizes $\rho$ over initial speed, payload, friction, and fixture-realizable smooth disturbances (unrealizable spikes produce INVALID trials on hardware) using tools like S-TaLiRo, Breach, VerifAI, CMA-ES, or Bayesian optimization. Keep F1's time-domain onset check separate from distance margins. Third, Step 3 warns that a violation refutes the claim, whereas an empty search certifies nothing outside the searched region.
