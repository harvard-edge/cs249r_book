# Volume III slide kit

Generated by `make kit V=3` from `slides/assets/kit/make_kit.py` (`VOLUMES[3]`). Do not edit the SVGs by hand; change the generator and rerun. Decks reach these files through `\mlsyskit` once `\mlsyssetup{volume=III}` is set; name a figure without its extension, as in `\mlsyskitfig{stack_runtime}`.

The stack has six layers, bottom to top, each one teaching part (numeral in the tab), with the Trajectory bar beside all of them. Layer labels are plain names; the book's computer-analogy tab labels are not used.

| File | What it shows | When a deck uses it |
|---|---|---|
| `stack` | The whole stack and the Trajectory bar, nothing lit | Lecture 0 and Lecture 20 map slides; any slide that needs the whole map |
| `stack_model` | Model layer lit (Part I) | `layer=model`: Lectures 2 and 3 (section dividers) |
| `stack_memory` | Memory layer lit (Part II) | `layer=memory`: Lectures 4, 5, 6 |
| `stack_tools` | Tools layer lit (Part III) | `layer=tools`: Lectures 7, 8, 9 |
| `stack_runtime` | Runtime layer lit (Part IV) | `layer=runtime`: Lectures 10 to 14 |
| `stack_learning` | Learning layer lit (Part V) | `layer=learning`: Lectures 15, 16, 17 |
| `stack_scale` | Agents at Scale layer lit (Part VI) | `layer=scale`: Lectures 18 and 19 |
| `stack_trajectory` | Trajectory bar lit, every layer dimmed | `layer=trajectory`: Lectures 1 and 20, which span the stack; also any slide on the trajectory as the unit of engineering |
| `stack_build1` to `stack_build7` | The stack built one layer per step from Model up; step 7 adds the Trajectory bar | Lecture 0, "What is an agentic system made of?" (`\mlsyssteps{\mlsyskit/stack_build}{7}`) |
| `stack_roadmap` | Every lecture number on its layer; L1 and L20 under the bar | Lecture 0, "Where does each lecture sit?"; a course-map recap in Lecture 20 |
| `course_order` | All twenty lectures in three columns by part, one line per lecture ("L10 Agent Harness"), drawn for a 15 by 6.2 cm slot so titles land near 9.5 pt; each part is one layer, so the part header names it and cards carry no layer tag | Lecture 0 course slide; Lecture 20 retrospective |
| `machine_step1` to `machine_step4` | One accelerator node built up: compute, SRAM, HBM, host and link | Where a lecture needs the hardware under the model: Lecture 2 (decode is memory bound), Lecture 5 (KV cache residency in HBM) |
| `machine_hl_compute`, `_sram`, `_hbm`, `_link`, `_host` | The node with one component outlined | Same lectures; `machine_hl_hbm` for KV footprint, `machine_hl_link` for host offload |

Not in the kit yet (listed in the course plan): the H·S·A locators (reuse the book SVGs), the trajectory strip, the six-phase turn, the horizon-compounding and cost-per-accepted-task plot generators, and the lighthouse icons.
