# Volume IV slide kit

Generated by `make kit V=4` from `slides/assets/kit/make_kit.py` (`VOLUMES[4]`). Do not edit the SVGs by hand; change the generator and rerun. Decks reach these files through `\mlsyskit` once `\mlsyssetup{volume=IV}` is set; name a figure without its extension, as in `\mlsyskitfig{stack_brain}`.

The stack has five levels, top to bottom Brain, Nervous System, Body, Boundary, World. A wider gap between Brain and Nervous System marks the proposal boundary (above may only propose, below may command), distinct from the causal boundary, which is the Boundary layer. A dashed outline labeled "Governance (Part IV)" surrounds all five levels; it is an envelope, not a layer. There are no part brackets.
