\begin{frame}{RDMA takes the kernel and host copies off the data path}
  \centering
  \mlsyssteps[width=0.92\textwidth,height=5.1cm,keepaspectratio]{rdma_path_step}{3}
  \mlsyscredit{Network Fabrics, \S3.4.1, figures 5 and 6, redrawn (interactive Explore figure: GPUDirect RDMA Data Path). Latencies: Definition 3.3.}
  \note{%
    \mlsysnotemeta{2 min}{Core}%
    This three-step path compares how bytes travel from one GPU's memory to another across servers. First, step 1 shows traditional TCP sockets: every byte bounces through host DRAM twice ($2n$ copies, user-to-kernel and kernel-to-NIC) while host CPUs run the transport stack. Second, step 2 introduces RDMA verbs, bypassing the OS kernel and offloading reliable transport directly to the NIC. Third, step 3 adds GPUDirect RDMA: the NIC reads and writes GPU HBM directly across PCIe ($0n$ host bounces), cutting startup latency to single-digit microseconds and shrinking $\alpha$ inside $T_{\text{comm}}$.

    \notecue{Watch for}{RDMA defines direct memory access and NIC offload; how the network handles dropped packets is a separate transport decision shown next.}

\begin{frame}{A full queue pauses its sender, and the pause spreads}
  \centering
  \mlsyssteps[width=0.9\textwidth,height=4.6cm,keepaspectratio]{pfc_spread_step}{3}\\[0.05cm]
  {\small PFC (priority flow control): a per-class PAUSE frame to the upstream port.}
  \mlsyscredit{Network Fabrics, Definition 3.8 and \S3.6.1 (Guo et al. 2016; Gangidi et al. 2024).}
  \note{%
    \mlsysnotemeta{2.5 min}{Core}%
    Follow the filled incast buffer into Priority Flow Control (PFC) on a lossless RoCE fabric across three build steps. First, step 1 fills one receiver port (red), which avoids dropping packets by sending per-class PAUSE frames upstream. Second, step 2 halts upstream switches, filling their buffers so pauses cascade backward tier by tier. Third, step 3 stalls the unrelated green flow heading to a healthy receiver simply because it shares a paused switch: congestion spreading creates victim flows. One slow receiver or degrading optic can trigger this (with 24,576 transceivers on 4,096 GPUs at a 0.001\% daily fault rate each, there is a 21.8\% daily chance of a degradation), and stalling even one victim flow halts the entire synchronous barrier, adding to both $T_{\text{comm}}$ and $T_{\text{sync}}$.

First, step 2 lays out the top-down diagnostic ladder: (1) check GPU utilization against the step timeline to separate compute/input stalls from communication, (2) verify \texttt{NCCL\_DEBUG=INFO} for accidental socket fallback, (3) run pairwise \texttt{ib\_write\_bw}, (4) inspect switch PFC/ECN counters, and (5) inspect physical port symbol and CRC errors. Then, step 3 catches one node pair at 24 GB/s versus 48 GB/s expected, where lane negotiation and symbol errors confirm a failing optical transceiver or cable.

    \notecue{Check}{Have pairs name the first check separating compute from fabric before revealing steps 2 and 3. Starting top-down from the step timeline and \texttt{NCCL\_DEBUG} isolates communication quickly before running pairwise RDMA tests. Jumping straight to swapping cables or blaming GPUs wastes hours when no hardware fault has been localized.}

    \notecue{Watch for}{Correlate port error counters with the slow collective window before pulling hardware from production.}

\begin{frame}{Takeaways}
  \small
  \begin{itemize}\setlength{\itemsep}{0.14cm}
    \item Synchronous training waits for its slowest transfer, so completion time and its tail measure a fabric.
    \item $T(n) = \alpha + n/\beta$: below $n^* = \alpha\beta$ (75 KB on NDR) startup sets the time; above it, bandwidth.
    \item Bisection bandwidth caps cut-crossing traffic; wiring such as rails should follow the parallelism plan.
    \item Lossless flow control can spread pauses and deadlock; congestion control and routing act first.
    \item Fabric faults usually slow a job silently; compare with a baseline and diagnose top down.
  \end{itemize}
  \note{%
    \mlsysnotemeta{1 min}{Core}%
    These five points mirror the five segments of the lecture: judging fabrics by synchronous collective tail time, applying $T(n) = \alpha + n/\beta$ around the 75 KB NDR knee, matching bisection and rail topology to parallelism, acting before lossless queues deadlock, and diagnosing silent link slowdowns top down against baselines.
