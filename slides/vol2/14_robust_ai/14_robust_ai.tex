\begin{frame}{How do we know a deployed model is still right?}

\begin{frame}{Three shifts change three different probabilities}
  \centering
  \mlsyssteps[width=0.92\textwidth,height=5.2cm,keepaspectratio]{shift_step}{3}\\[0.05cm]
  {\footnotesize $x$: the input.\quad $y$: its label.\quad $P(y \mid x)$: the labeling rule. The shift taxonomy names what moved.}
  \mlsyscredit{Redrawn from Robust AI, figure 3 (illustrative points).}
  \note{[2.5 min] [CORE] Step 1: covariate shift. Inputs move to a new region (amber); the boundary, the labeling rule, stays. Remedy: reweight or collect data where the new inputs fall. Step 2: label shift. Class frequencies change while each class looks the same, as respiratory illness rose in hospital case mix during COVID-19. Remedy: re-estimate priors and recalibrate. Step 3: concept drift. The same inputs get new labels because the rule itself moved, and points between the old and new boundary (red) become errors. Fraud is the classic case; adversaries change what fraud looks like. Remedy: adapt on fresh labels, which is why concept drift costs more to fix. ENGAGE: a new policy changes which loan applicants repay, with the same applicants applying. Which shift? (Expected: concept drift; $P(y \mid x)$ changed, $P(x)$ did not.) WARN: monitors that watch inputs see only $P(x)$. Lecture 12 placed drift monitors across the fleet; this lecture says what each kind of shift is and what evidence separates them. FLEX: [CORE].}
\end{frame}

A dense GPT-3-class model reads all \val{gpt3_params_b} billion parameters on every forward pass, so that weight joins every request the replica serves until something notices. A golden canary replays fixed requests through each replica and compares outputs with stored references, compute plus communication. Cross-replica comparison doubles the work on a sampled request. Deciding which replicas and checkpoints to trust after a failure is coordination. ENGAGE: which check catches a flip that keeps the value in range? (Expected: the canary or cross-replica comparison, not the range check.) FLEX: [CORE].}
\end{frame}

\begin{frame}{Takeaways}
  \normalsize
  \begin{itemize}\setlength{\itemsep}{0.18cm}
    \item Shift, attacks, poisoning, and faults keep health signals green; claim robustness per failure class.
    \item A drift alert opens an investigation; labels and a root cause justify a model update.
    \item Answering fewer requests lowers error only if fallback capacity absorbs the rest.
    \item Attacker access sets the test; defenses cost training passes or serving samples.
    \item Read release timing, replay, and telemetry before choosing a defense.
  \end{itemize}
  \note{[1 min] [CORE] One line per segment. Ask students which slide taught each. If short on time, read the first and the last.}
\end{frame}
