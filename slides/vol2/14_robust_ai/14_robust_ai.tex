\begin{frame}{Three shifts change three different probabilities}
  \centering
  \mlsyssteps[width=0.92\textwidth,height=5.2cm,keepaspectratio]{shift_step}{3}\\[0.05cm]
  {\footnotesize $x$: the input.\quad $y$: its label.\quad $P(y \mid x)$: the labeling rule. The shift taxonomy names what moved.}
  \mlsyscredit{Redrawn from Robust AI, figure 3 (illustrative points).}
  \note{%
  \mlsysnotemeta{2.5 min}{Core}%
  Build the shift taxonomy across three steps. Step 1 (covariate shift): inputs $P(x)$ move to a new region (amber) while decision boundary $P(y \mid x)$ stays fixed; remedy by reweighting or collecting data in the new region. Step 2 (label shift): class frequencies $P(y)$ change while each class looks similar (such as hospital respiratory case mix during COVID-19); remedy by re-estimating priors and recalibrating. Step 3 (concept drift): the labeling rule $P(y \mid x)$ itself moves (such as evolving fraud tactics or new loan-repayment policies under unchanged applicants), turning points between old and new boundaries (red) into errors; fixing it requires fresh labels, making it the costliest shift.

  \notecue{Watch for}{Input monitors placed across fleets (Lecture 12) watch $P(x)$ only and stay blind when $P(y \mid x)$ shifts.}

  \notecue{Next}{Real ImageNet-V2 data next demonstrates how even an unintentional, invisible shift drops accuracy across every model.}
}
\end{frame}

Step 2: flipping bit 30 (top exponent bit) multiplies it by $2^{128}$ to a finite $1.4 \times 10^{37}$, bypassing NaN/infinity checks while ECC DRAM misses logic flips; a dense 175B model reads that corrupted weight on every request. Step 3 prices three checks on $C^3$: range checks compare against training bounds (compute, misses in-range flips), golden canaries replay fixed requests per replica (compute + comm), and cross-replica comparison doubles sampled work, while deciding which replicas to trust is coordination.

  \notecue{Next}{Students now diagnose a realistic credit-risk drift alert to separate shift, attack, and pipeline fault.}
}
\end{frame}

\begin{frame}{Takeaways}
  \normalsize
  \begin{itemize}\setlength{\itemsep}{0.18cm}
    \item Shift, attacks, poisoning, and faults keep health signals green; claim robustness per failure class.
    \item A drift alert opens an investigation; labels and a root cause justify a model update.
    \item Answering fewer requests lowers error only if fallback capacity absorbs the rest.
    \item Attacker access sets the test; defenses cost training passes or serving samples.
    \item Read release timing, replay, and telemetry before choosing a defense.
  \end{itemize}
  \note{%
  \mlsysnotemeta{1 min}{Core}%
  Walk through the five takeaways, one per segment: claim robustness per failure class, require labels and root cause before retraining on drift alerts, bound selective abstention by fallback capacity, match adversarial defenses to attacker access and compute budgets, and read timing, replay, and telemetry before buying a fix. Emphasize the first and fifth lines if short on time.

  \notecue{Next}{An optional slide offers three open research and system-design questions for discussion.}

\begin{frame}{Open questions}
