Economics: exposure is priced by time; at the delayed-alert rate of Napkin Math 12.6, about \$1.08M a day, each hour costs about \$45K (derived; that notebook's traffic and click value, not Example 12.2's, which gives no dollar value). WARN: no single control suffices; the hook passed every per-model gate. ENGAGE: which control is cheapest to add? (Expected: the null-rate gate, a check on data the pipeline already reads.) \begin{frame}{Takeaways}
  \normalsize
  \begin{itemize}\setlength{\itemsep}{0.18cm}
    \item The unit to operate is the dependency graph; a release names its impact set and a compatible version set.
    \item A feature is a versioned interface; join on availability time, version semantic changes.
    \item Exposure is share times time; one versioned contract binds all release evidence.
    \item Alerts route by level to owners, and the worst SLO dimension stops promotion.
    \item Owning pays only above a sustained useful utilization; the dominant cost term picks the fix.
  \end{itemize}

\end{frame}
