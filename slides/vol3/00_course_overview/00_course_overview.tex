\begin{frame}{A steam-engine governor closes its loop on measured speed}
  \begin{columns}[c]
    \begin{column}{0.46\textwidth}
      \centering\safeimg[width=\textwidth,height=5.4cm,keepaspectratio]{steam-engine-governor.jpg}
    \end{column}
    \begin{column}{0.50\textwidth}
      \normalsize
      The spinning balls measure the engine's speed and move the steam valve.\\[0.4cm]
      \uncover<2->{An agent is a model inside a loop that software closes. The loop runs commands and reads back what happened.}
    \end{column}
  \end{columns}
  \mlsyscredit{Photo: centrifugal governor on an Allis-Chalmers steam engine, brewbooks (CC BY-SA 2.0), Wikimedia Commons.}
  \note{%
  \mlsysnotemeta{2.5 min}{Core}%
  First, look at the mechanical centrifugal governor: as shaft speed rises, the spinning weights swing outward and throttle the steam valve; as speed drops, they fall and open it. Because the loop senses actual shaft speed rather than the throttle command, it corrects real disturbances, the core principle of feedback control (Wiener, 1948). Next, the reveal maps that mechanism onto an agent: the language model proposes an action, software runs the command, and the measured output returns as the next observation, just as in the 22 Django calls.

  \notecue{Watch for}{Unlike a physical governor reading shaft speed, a model emits untrusted text proposals that can be fluent and wrong, so software must validate and bound every action before executing it.}

  \notecue{Next}{To see how much that feedback loop matters in practice, compare the exact same models with and without a loop.}}
\end{frame}

\begin{frame}{An agentic system is six layers serving one task}
  \begin{columns}[c]
    \begin{column}{0.60\textwidth}
      \centering
      \only<1|handout:0>{\mlsyskitfig[width=\textwidth,height=5.5cm,keepaspectratio]{stack_build2}}%
      \only<2|handout:0>{\mlsyskitfig[width=\textwidth,height=5.5cm,keepaspectratio]{stack_build4}}%
      \only<3|handout:0>{\mlsyskitfig[width=\textwidth,height=5.5cm,keepaspectratio]{stack_build6}}%
      \only<4-|handout:1>{\mlsyskitfig[width=\textwidth,height=5.5cm,keepaspectratio]{stack_build7}}%
    \end{column}
    \begin{column}{0.37\textwidth}
      \normalsize
      \only<1|handout:0>{\textbf{Model and Memory}\\[0.15cm]\small One call returns a proposal, its tokens, and its price; memory chooses what each call reads and keeps.}%
      \only<2|handout:0>{\textbf{Tools and Runtime}\\[0.15cm]\small Tools bound allowed actions in sandboxes; the runtime runs the loop, enforces limits, recovers, and evaluates.}%
      \only<3|handout:0>{\textbf{Learning and Scale}\\[0.15cm]\small Learning trains on recorded runs; scale splits work across agents and prices each accepted task.}%
      \only<4-|handout:1>{\textbf{Trajectory}\\[0.1cm]\small Every layer serves the record of one task, from first request to finish.\\[0.25cm]Django run: 22 calls (Model), growing prompts (Memory), container commands (Tools), loop and stop rule (Runtime).}%
    \end{column}
  \end{columns}
  \note{%
  \mlsysnotemeta{4 min}{Core}%
  This stack is the roadmap that appears on every lecture divider throughout the term. Build it bottom up in four steps. First, Model and Memory: one model call returns a proposal at a token price, while memory selects what each call reads and what persists across tasks. Second, Tools and Runtime: tools bound permitted actions inside sandboxes, and the runtime executes the loop, enforces limits, recovers from crashes, and evaluates outcomes. Third, Learning and Scale: training improves models from recorded runs, and scale coordinates multiple agents while pricing each accepted task. Finally, the vertical Trajectory bar spans all six layers because one task's complete record is our unit of engineering, illustrated on the right by the Django run.

  \notecue{Watch for}{These layers are tightly coupled rather than independent silos: a memory decision immediately alters serving cost, latency, and runtime reliability.}

  \notecue{Next}{Test this six-layer map by diagnosing which layer failed in six real production and benchmark incidents.}}
\end{frame}
