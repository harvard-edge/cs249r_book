  \mlsysnotemeta{2.5 min}{Core}%
  Inspect the real \texttt{config.json} excerpt from Meta Llama 3.1 70B and trace Equation 1 in three clicks. First, head dimension equals \texttt{hidden\_size} divided by \texttt{num\_attention\_heads}: $8{,}192 / 64 = 128$. \begin{frame}{Before paging, at most 38\% of KV memory held token state}
  \centering
  \safeimg[width=0.95\textwidth,height=5.1cm,keepaspectratio]{kwon_fig2.pdf}\\[0.05cm]

  \note{%
  \mlsysnotemeta{2.5 min}{Core}%
  Kwon et al. (SOSP 2023) profiled contiguous KV allocators on OPT-13B under three length strategies: reserving for the model's maximum length (Max), next power of two (Pow2), or even exact oracle final lengths known in advance (Oracle). Actual token state (green) occupied only 20.4\%, 26.8\%, and 38.2\% of KV memory; the remainder was lost to reserved future slots (orange), internal slack (red), and unusable external gaps (gray), whereas paged vLLM reached 96.3\%. \begin{frame}{Reservation strands slots inside; contiguity strands gaps outside}

  \mlsysnotemeta{1.5 min}{Optional}%
  This two-step diagram separates Randell's (1969) two fragmentation losses. First, reserving a 32,768-token contiguous slot at admission strands 30,720 unused slots when a request finishes at 2,048 tokens (internal fragmentation and reservation slack). Second, three free 256-slot extents total 768 free slots yet reject a 512-slot request because standard attention kernels index by fixed stride from one base pointer (external fragmentation).   \centering
  \safeimg[width=0.78\textwidth,height=5.0cm,keepaspectratio]{atlas-manchester-1963.jpg}\\[0.1cm]

  \note{%
  \mlsysnotemeta{0.5 min}{Core}%
  Photographed in January 1963, the University of Manchester Atlas introduced paged virtual memory (Kilburn et al., 1962): a page table translated a program's contiguous logical addresses onto scattered fixed-size frames in physical core memory. Sixty years later, PagedAttention applied that exact indirection to KV caches.

\begin{frame}{A block table maps token positions to blocks anywhere in HBM}
  \centering
  \mlsyssteps[width=0.95\textwidth,height=6.0cm,keepaspectratio]{blocktable_step}{3}
  \mlsyscredit{KV Cache Management, \S5.4.1 (Explore: PagedAttention on mlsysbook.ai; 4-token blocks). After Kwon et al., SOSP 2023.}
  \note{%
  \mlsysnotemeta{2.5 min}{Core}%
  Follow the three-step build using 4-token blocks. First, a 10-token sequence splits into logical blocks 0 (tokens 0--3), 1 (4--7), and 2 (8--9, leaving two empty slots). Second, the sequence's block table maps logical blocks 0, 1, 2 to non-contiguous physical blocks 3, 7, and 9 anywhere in HBM; growing sequences simply grab any free physical block without copying or pre-reserving. Third, the kernel locates token 9 via logical block $\lfloor 9/4 \rfloor = 2 \to$ physical block 9, offset $9 \bmod 4 = 1$. Any free block serves any request, removing external fragmentation completely, while worst-case internal waste is under one block (15 slots = 4.92 MB for 16-token blocks; 20.64 MB, or 0.2\% of 32K, for 64-token blocks).

  \notecue{Watch for}{A mapped physical block provides capacity, yet only initialized slots contain valid keys and values.}

\end{frame}

          evict_callback: Callable):
    leaves = self._collect_leaves()
\hl{    heapq.heapify(leaves)}
    num_evicted = 0

\begin{frame}{Little's law turns occupied slots into a turn rate}
  \centering
  {\Large $L = \lambda\,W$}\\[0.15cm]
  {\small $L$: slots held on average \quad $\lambda$: turns per second \quad $W$: time each turn holds its slot}\\[0.3cm]
  \safeimg[width=0.92\textwidth,height=3.0cm,keepaspectratio]{residency.pdf}\\[0.1cm]
  \uncover<2->{\small Residency tax of a kept wait $= 1 + T_{\text{tool}}/T_{\text{model}} = 1 + 45/5 = \mathbf{\textcolor{mlsysaccent}{10}}$}
  \mlsyscredit{Little, Operations Research, 1961. KV Cache Management, theorem 5.1 and \S5.8.2.}
  \note{%
  \mlsysnotemeta{2 min}{Core}%
  Little's law (1961), $L = \lambda W$, holds for any stable queueing system regardless of arrival distribution: average occupied slots $L$ equal turn rate $\lambda$ times mean slot residence time $W$, so $\lambda = L / W$. Step 1 contrasts one repair turn: holding KV state across the 45 s test gives $W = 5 + 45 = 50\text{ s}$, whereas releasing state during the test gives $W = 5\text{ s}$. Step 2 isolates the residency tax of keeping paused state: $1 + T_{\text{tool}}/T_{\text{model}} = 1 + 45/5 = 10$ (a 90 s test would yield a 19$\times$ tax).

  \notecue{Watch for}{Omitting idle tool waits from $W$ overstates memory-bounded throughput by exactly $1 + T_{\text{tool}}/T_{\text{model}}$, and because Little's law governs averages, burst sizing requires separate headroom. Later lectures on sandboxes, harnesses, and economics reuse this exact relation.}
