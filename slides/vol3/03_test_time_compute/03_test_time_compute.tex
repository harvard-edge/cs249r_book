\begin{frame}{Benchmarks estimate pass@k from n samples without bias}

  {\small $n$ samples, $c$ pass. Example: $n = \val{est_n}$, $c = \val{est_c}$, $k = \val{est_k}$.}\\[0.1cm]
  \uncover<2->{\small Subset estimate \textbf{\val{est_subset}}; the plug-in $1-(1-c/n)^k$ gives \val{est_plug}, biased low.}
  \mlsyscredit{openai/human-eval, human\_eval/evaluation.py @ b9453e8, lines 22 to 28 (MIT License); Chen et al., 2021. Example: Test-Time Compute, Exercise 2(d) (derived).}
  \note{[1.5 min] [OPTIONAL] Real code from the repository that introduced pass@$k$ for code (Chen et al. 2021). Generate $n$ samples per task, count the $c$ that pass.
