MLPerf EDU: An Executable Benchmark Suite for ML Systems Education

Connecting industrial benchmark rigor to single-laptop execution using zero-discretion target inheritance, fail-closed admission control, and the Data-Algorithm-Machine (DAM) Taxonomy.

Launch Interactive Dashboard 📊 Download Paper (14-Page PDF)

Core System Invariants

Bridging production benchmarking discipline to single-node consumer hardware.

🎯

Zero-Discretion Target Inheritance

Every workload inherits its quality gate directly from upstream MLPerf and MLCommons authorities. Targets are never locally relaxed or dropped for constrained hardware.

🔒

Fail-Closed Admission Engine

Enforces four strict admission gates: $\operatorname{admit}(r) = G_{\text{sem}} \land G_{\text{protocol}} \land G_{\text{provenance}} \land G_{\text{state}}$. Any procedural violation is treated as a hard failure.

⚙️

DAM Taxonomy Lenses

Structured exploratory trade-off analysis across Data (Andrew Ng Data-Centric AI), Algorithm (Model compression & optimizers), and Machine (Roofline operational intensity).

🎓

Backward Design Pedagogy

Engineered backward from desired student learning goals (Wiggins & McTighe 2005) with 4 hands-on profiling labs, devcontainers, and cryptographic `.provd.json` manifests.

Quickstart Installation & Execution

Run the complete single-laptop suite in under 30 seconds.

terminal bash 
# Install MLPerf EDU Python Package
pip install mlperf-edu

# Execute 30-second CI/CD Plumbing Check
mlperf run --profile min

# Execute Canonical Reference Baseline
mlperf run --profile max --workload image-classification

# Launch Interactive Profiling & DAM Taxonomy Explorer
mlperf dashboard --port 8080
