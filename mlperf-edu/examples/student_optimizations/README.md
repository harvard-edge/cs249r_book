# Assignment Starter Files

The two `stub_*.py` files in this directory are intentionally incomplete
student assignment starters. They are not reference implementations, runnable
examples, benchmark baselines, or valid submissions. The main lab guide does
not advertise them as executable workflows.

An instructor who assigns either starter must define the missing implementation
and acceptance criteria. Finished work should be validated against a registered
workload and should preserve its declared quality contract. Do not use output
from these files as MLPerf EDU evidence.
