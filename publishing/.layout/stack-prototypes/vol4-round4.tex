{\large\bfseries Volume IV, round 4 --- corrected measurement, corrected type}\par\vspace{2pt}
{\footnotesize Rounds 1--3 were built on a number I estimated by eye rather than measured.
``Nervous System'' set in Palatino \texttt{\textbackslash scriptsize}\,bold is
\textbf{59.70\,pt = 2.098\,cm}, not 2.55\,cm, against 2.480\,cm of usable rung. It fits with
3.8\,mm to spare, so vol1's boxed geometry was never ruled out. Labels below are real
Helvetica; tints are restricted to 0 / 22 / 90 because no text colour is legible on a
31--84 tint; the secondary line is 7\,pt, never 5.4\,pt.}\par\vspace{8mm}

{\footnotesize\textbf{The open question the reviewers split on.} The cadence is
chapter-invariant: it is identical on all seventeen appearances. One reviewer called that
seventeen repetitions of noise and would cut it, putting the rates once at full size where the
stack is introduced --- which is exactly how vol1 already splits
\texttt{\textbackslash mlsysstack} from \texttt{\textbackslash mlsysstackfull}. Two others
would keep it, because vertical position encodes order but not interval, and these intervals
span four orders of magnitude.}
